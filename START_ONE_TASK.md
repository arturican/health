# Как начать одну задачу

> Выполни Txxx по AGENTS.md: только эта задача, подходящие проверки,
> обновление TASKS/PROGRESS и один локальный коммит. Без push и деплоя.

Вместо ID можно попросить «следующую доступную задачу»: выбор — по TASKS.md
с проверкой зависимостей. Если карточки нет, сначала сформулируй её критерии.
Маршруты поиска кода и документов — [PROJECT_MAP.md](docs/PROJECT_MAP.md).
Не требуется заранее читать весь README, журнал прогресса и спецификации.

Несколько явно согласованных этапов выполняются последовательно, каждый отдельным
коммитом. После согласованного объёма — остановка; IDEAS не разрешает реализацию.
