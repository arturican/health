# Сценарии проверки

Этот файл описывает критерии, а не результаты запуска. Фактические проверки
записываются в [PROGRESS.md](PROGRESS.md).

## T001: стартовая оболочка

- Production-приложение открывается без ошибок страницы и консоли.
- На странице один основной заголовок «Дневник здоровья» и понятный стартовый текст.
- Ссылка «Что будет в дневнике» ведёт к существующему разделу; доступна клавиатурой.
- На ширине 375 px нет горизонтального переполнения и текст остаётся видимым.
- Сборка не требует внешних шрифтов, аналитики, API или медицинских данных.

## Будущие задачи

| Область | Обязательные сценарии при её реализации |
|---|---|
| Числа и даты, T005 | Пробелы, запятая/точка по согласованному формату, пустое значение, NaN/Infinity, границы, несуществующая дата, часовой пояс |
| Профиль и вес, T009–T017 | Создание, ошибка ввода, атомарное сохранение, редактирование, удаление, перезагрузка, отсутствие измерений |
| Питание, T019–T027 | Размер порции, снимок продукта, архивирование без изменения истории, пустой день, неполный день, копирование на дату |
| Backup, T028–T030 и T055–T057 | Неверная схема/версия, повреждённый файл, дубликаты, отмена, отсутствие частичного восстановления при ошибке |
| Активность и энергия, T031–T040 | Нет данных отдельно от нуля, разные величины цели и расхода, отсутствие двойного учёта одной активности |
| Вложения, T043–T054 | Неверный MIME/размер, повреждённый файл, очистка EXIF, освобождение object URL, удаление связанных данных |
| Приватность, T058 и T062 | Удаление всех данных, подтверждение удаления, отсутствие внешней передачи, отсутствие личных данных в логах/репозитории |

Формулы, численные границы и схемы не выводятся из названий задач. Сначала уточняется
карточка и соответствующая спецификация, затем пишутся тесты и реализация.
