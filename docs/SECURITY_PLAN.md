# Очередь безопасности после T198

Пользователь разрешил последовательное выполнение локальных задач безопасности.
Источник статусов — [TASKS](../TASKS.md). Каждый этап ограничен пятью файлами
приложения и 250 строками реализации; тесты/документы считаются отдельно.

| Этап | Наблюдаемый результат |
|---|---|
| [T199](tasks/T199.md) | Очередь, критерии и границы |
| [T200](tasks/T200.md) | Исходный IP и защита от подделки forwarded |
| [T201](tasks/T201.md) | Лимиты входа/почты сохраняются при рестарте |
| [T202](tasks/T202.md) | Проверенная CSP без поломки приложения |
| [T203](tasks/T203.md) | Отзыв восстановленных сессий и ссылок |
| [T204](tasks/T204.md) | История секретов, итоговые проверки и порядок выпуска |
| [T205](tasks/T205.md) | Отдельно разрешённое внедрение на VPS |

Основание — [аудит T198](SECURITY_AUDIT_T198.md); исправленная гонка HTTP остаётся
закрытой. Эта очередь усиливает защиту и проверяемость; не объявляет все риски
уязвимостями и не обещает абсолютную безопасность.

## Решения и границы

- Для proxy сохраняется безопасное поведение по умолчанию. Доверие включается
  отдельно вместе с конфигурацией Nginx, которая заменяет клиентские заголовки.
- Счётчики находятся в существующей PostgreSQL; Redis/новый сервис не нужны.
  Миграция проверяется только в выделенных локальных БД, production не меняется.
- CSP разрешает необходимые inline-стили интерфейса, но не inline-JavaScript.
- После восстановления копии отзываются и сессии, и email-ссылки. Старый архив
  также может вернуть старый пароль и удалённые данные; это требует проверки
  оператора до открытия API.
- PDF остаются исходными скачиваемыми файлами. Антивирус/переписывание PDF,
  шифрование рабочей БД, пользовательских JSON и изменение retention требуют
  самостоятельного продуктового/операционного решения. В [итоге T204](SECURITY_RELEASE.md) даны конкретные
  варианты и критерии, без незаметного изменения формата/ключей/удаления архивов.
- Никаких production-атак, push/деплоя, реальных данных и автоматической ротации
  секретов. T205 остаётся невыполненной до отдельного разрешения по AGENTS.md.

Проверенные результаты, границы сканирования и порядок выпуска/отката —
[SECURITY_RELEASE](SECURITY_RELEASE.md).
