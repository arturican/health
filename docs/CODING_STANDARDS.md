# Правила кода

## Текущая основа

React + TypeScript + Vite; npm; обычный CSS. Все прямые зависимости фиксируются
точными версиями и lock-файлом. Версия Node фиксируется в `.nvmrc`, допустимая
ветка — в `package.json`. Не добавляй библиотеку без необходимости текущей задачи.

Актуальные точки входа UI/API, слои данных и расположение тестов —
[PROJECT_MAP.md](PROJECT_MAP.md). Новые области добавляются только в согласованной задаче.

## TypeScript и React

Включены `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes` и
проверка неиспользуемого кода. Запрещены `any`, `@ts-ignore`, `as unknown as`
и отключение правил ради прохода проверки. Внешний ввод имеет тип `unknown`
до проверки структуры и допустимых значений.

Расчёты — чистые функции вне JSX. Производные значения вычисляются из источника
данных, а не дублируются в state. Не мутируй props или состояние. Эффекты нужны
для взаимодействия с внешней системой, а не для простого вычисления суммы.

## Интерфейс

Тексты по-русски, идентификаторы по-английски. Используй семантический HTML,
подписи полей, видимый focus и доступ с клавиатуры. Цвет не должен быть единственным
носителем смысла. Для отсутствующих данных показывай пустое состояние; не выдумывай
нули или демонстрационные медицинские показатели.

Не создавай неработающие кнопки или обещания ещё не реализованных функций.
Различай возможность текущего экрана и план будущего продукта.

## Ошибки и данные

Ошибки ввода понятны пользователю и привязаны к полю. Не скрывай ошибки сохранения.
Даты записей и моменты времени имеют разные модели; формат и границы описываются
в карточке до реализации. Подробности вычислений — в [CALCULATIONS.md](CALCULATIONS.md),
работы с личными данными — в [PRIVACY_SECURITY.md](PRIVACY_SECURITY.md).
