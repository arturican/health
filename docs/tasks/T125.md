# T125 — первый деплой на VPS

Зависимость: T124. Пользователь разрешил первый деплой на VPS
159.194.208.200 и последующую автоматизацию из dev отдельным этапом T126.

## Результат

Проверенная статическая сборка доступна по HTTPS на согласованном адресе.
Существующие сайты и сервисы VPS продолжают работать. Данные дневника остаются
в IndexedDB браузера; backend и синхронизация не добавляются.

## Объём

- Отдельный каталог релизов, атомарное переключение и инструкция отката.
- Установщик принимает только ограниченный архив статической сборки.
- Отдельный виртуальный хост существующего Nginx и сертификат HTTPS.
- Документация размещения, проверки и границ локального хранения.

## Критерии и проверки

- `npm run check`, тесты установщика и `git diff --check` проходят.
- `nginx -t` проходит до reload; чужая конфигурация не изменяется.
- HTTPS действителен, HTTP перенаправляется, HTML/assets доступны.
- Браузер открывает приложение; синтетическая запись сохраняется после reload.
- Неуспешная установка не переключает текущий релиз; откат проверен.
- Приватные ключи и пользовательские данные отсутствуют в репозитории.

Коммит: `chore(deploy): T125 опубликовать приложение на VPS`

разрешения согласно AGENTS.md.
