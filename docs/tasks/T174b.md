# T174b — Вход и восстановление сессии

Зависимость: T174a. Русская форма входа, повтор проверки подключения и выход.
Сессия публикуется только вместе с актуальным diary-state, без промежуточного
открытия дневника. Смена сессии пересоздаёт содержимое и задаёт часовой пояс дат.
Выход подтверждается сервером; при ошибке остаётся доступен повтор.

Область: client/auth.ts, client/AuthBoundary.tsx, client/session.ts, domain/input.ts.
Проверки: существующая/отсутствующая сессия, неверный пароль, сбои и повтор,
ожидание diary-state, logout, часовой пояс и StrictMode; npm run check, diff --check.
