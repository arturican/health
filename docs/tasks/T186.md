# T186 — Локальный SMTP с DKIM на VPS базы данных

Зависимость: T185. Пользователь поручил подобрать и установить почтовую службу
на 2.26.54.81 для будущих подтверждений почты и восстановления доступа.
Результат: Postfix + OpenDKIM из Ubuntu 24.04, только loopback SMTP,
подпись отправителя no-reply@auth.arturican.com и подготовленные DNS-записи.

Область: deploy/mail-* и проверка конфигурации, документация и статусы.
Проверки: postconf/postfix check, opendkim -n, SMTP только localhost,
отказ постороннему отправителю, DKIM в синтетическом письме, очистка только
его queue id, отсутствие адресов в журнале, health API/доступность БД,
Python deploy tests, check:docs, git diff --check.

Исходящий TCP/25 к Gmail и Яндексу доступен, существующих MTA нет.
Установка не обновляет и не перезапускает прежние сервисы. Приватный DKIM-ключ
создаётся только на VPS с ограниченными правами; в Git — только конфигурация
и публичные записи. До подтверждения A/SPF/DKIM/DMARC/PTR внешний SMTP-транспорт
отложен. Активация внешней доставки требует DNS у владельца домена/хостера;
этот результат не выдаётся за доставленное в пользовательский ящик письмо.
Изменения авторизации приложения и почтовые ящики/IMAP не входят в эту задачу.
