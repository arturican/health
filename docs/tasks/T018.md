# T018 — CI с закреплённым Node и браузерными quality gates

Зависимость: T017.

Наблюдаемый результат: CI с закреплённым Node и браузерными quality gates.

## Критерии

- CI запускает npm ci и полный check на Node из .nvmrc с Chromium.
- Push/PR dev/master и ручной запуск, ограниченные права и SHA actions.
- Workflow валиден, локальные gates проходят; удалённый статус проверяется после push.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `.github/workflows/check.yml`, `docs/TESTING.md`, `docs/DEPENDENCIES.md`.
