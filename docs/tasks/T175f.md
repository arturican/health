# T175f — Единое переключение на API

Зависимость: T175e9. Пять файлов приложения: dataAccess, main, App, TodayPage,
vite.config. Единственный рабочий источник — API; вход до открытия дневника,
загрузка/ошибки/повтор и выход, правдивый текст о серверном хранении.
Нет автоматического импорта браузерных данных или fallback в IndexedDB.

Изолированные unit/browser UI-тесты явно используют legacy-фикстуры.
Production E2E используют настоящий HTTP API с ограниченной ролью PostgreSQL,
случайную тестовую БД и отдельный синтетический аккаунт каждого сценария.
Фиксированное время задаётся только тестовой фабрикой; production без тестового режима.
Один E2E worker учитывает общий слот операций больших копий.

Проверки: прежние 54 сценария через API, дополнительные вход/выход/ownership/
перезагрузка и отсутствие браузерного хранения; npm run check, diff --check,
сборка без Dexie/серверных секретов. Существующие данные браузера не меняются.
Тестовый setup соответствует [Playwright](https://playwright.dev/docs/test-global-setup-teardown).
