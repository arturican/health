# T136 — Desktop-макет питания

Зависимость: T135 и одобренный пользователем локальный макет «Сегодня».
Запрос разрешает последовательно T136–T142; адаптивность — позже.
Это локальные SVG/PNG, не завершение заблокированной нативной Figma-задачи T133.

## Результат и границы

Экран питания 1440 px и лист форм/состояний в стиле одобренной главной.
Только макеты в design/desktop; исходники приложения и зависимости не меняются.
Общие средства сборки/проверки и галерея вводятся здесь для следующих экранов.

## Критерии

- Дневной итог, БЖУ, полнота, цель и отдельная оценка расхода.
- Запись/правка порции, дата при правке, комментарий, удаление с подтверждением.
- Каталог с поиском, архивированием/возвратом; новый/изменяемый продукт,
  ккал и необязательные БЖУ на 100 г, источник.
- Копирование приёма на другую прошлую дату; нет данных, загрузка,
  ошибка валидации, сохранение, ошибка хранения и успешная запись.
- Только синтетические значения, суммы согласованы; неизвестное не равно нулю.
- SVG содержит текст и векторы; PNG просмотрен; шрифт, границы, пересечения
  текстов и контраст проверены. Импорт в Figma не объявляется проверенным.
- Проверка документации и git diff --check; отдельный локальный коммит.

Коммит: `docs(design): T136 создать Desktop-макеты питания`.
