# T264b — Автоматический setup с получением секретов через SSH

Зависимость T264a. Пользователь выбирает VPS только для секретов и просит
автоматизацию. Результат: npm run setup после clone/Node/Docker/SSH доступа;
SOPS/age и перенос приватного age key на новом ПК не требуются.

Файлы реализации: scripts/secrets.mjs, scripts/local.mjs, scripts/setup.mjs,
scripts/grant-development-access.mjs, package.json — до 5/250 строк изменений.
Тесты отдельно. Существующий local SOPS режим сохраняется как явный fallback;
init нового набора остаётся operator-only local. Новых dependencies нет.

Критерии: SSH по умолчанию с pinned host key/BatchMode/no-forwarding; значения
только stdin/захваченный stdout, timeout и безопасная ошибка. Existing .env и
.env.local, dirty refresh и stale local/upstream guards сохраняются. Setup
устанавливает dependencies только при несовпадении lock metadata; не удаляет
БД/данные и не меняет пароли. Grant добавляет только явно указанный public key
с forced command через существующий operator root SSH, не меняет иные доступы.

Проверки: старые local SOPS tests + SSH fixture success без локального key/SOPS,
missing SSH, partial failure, unknown fields, dirty refresh, stale local version;
live restore/refresh через dedicated account, negative grant, syntax/lint/docs.
Clean clone с отсутствующим age key и full check/build:api — T264c.
