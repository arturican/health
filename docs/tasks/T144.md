# T144 — Анализы, проверка распознавания и динамика показателей

Зависимость: T143. Пользователь уточнил назначение раздела документов:
только анализы, распознавание с проверкой пользователем, затем графики.

## Результат и границы

Desktop-макет documents.cjs и производные SVG/PNG/JSON; краткая документация.
Это будущий сценарий, заменяющий прежний макет универсальных документов.
Приложение, модель данных, OCR/AI, сервер и отправка файлов не реализуются.
Адаптивность и остальные экраны не входят в задачу.

## Критерии

- Только бланки анализов: загрузка → распознавание → сверка → подтверждение.
- Распознанные значения остаются черновиком до проверки. Показаны исходный
  фрагмент бланка, дата забора, название, значение, знак, единицы, референс;
  пользователь может исправить поле или исключить строку.
- График использует только подтверждённые сопоставимые числовые результаты
  одного показателя, единиц и метода; дата — дата забора, не загрузки файла.
- Точки и история берутся из одного синтетического набора; расстояния по оси
  времени соответствуют датам. Выбранная точка связана с исходным анализом.
- Изменение относительно предыдущего результата описано нейтрально.
  Не вводятся нормы, диагнозы и автоматические оценки «лучше/хуже».
  Референсы переносятся с конкретного бланка, не выдумываются.
- Нет данных, одна точка, несовместимые единицы/метод, текст и значения со
  знаками < или > не превращаются в вымышленные точные точки.
- Есть ожидание/ошибка распознавания, ручной запасной путь, проверка,
  успешное подтверждение, ошибка сохранения и удаление с влиянием на историю.
- PNG просмотрены; даты/значения/разность/геометрия/контраст и галерея проверены.
  check:docs и git diff --check проходят; пакет Desktop и ZIP обновлены.
- Отдельный локальный коммит; реализация распознавания требует отдельной задачи.

Коммит: `docs(design): T144 переработать документы в анализы с динамикой`.
