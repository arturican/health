# T022 — Каталог продуктов с поиском, правкой и архивом

Зависимость: T021.

Наблюдаемый результат: Каталог продуктов с поиском, правкой и архивом.

## Критерии

- Поиск без учёта регистра, переключатель архива, правка и отмена доступны через UI.
- Архивирование обратимо и не удаляет продукт; правка сохраняет текущий статус архива.
- Мобильный каталог не выходит за ширину страницы, доступные имена действий содержат продукт.
- Подпись кнопки входит в её доступное имя; сгенерированные артефакты браузера исключены из Git.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/productRepository.ts`, `src/pages/ProductForm.tsx`, `src/pages/ProductCatalog.tsx`, `src/pages/NutritionPage.tsx`, `src/styles.css`, `src/data/productRepository.test.ts`, `src/pages/ProductForm.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`.
