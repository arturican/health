# T162 — создание аккаунта

Зависимость: T161. Администратор создаёт аккаунт через закрытое окружение;
публичной регистрации нет. Пароль 15–1024 символа, без обрезки пробелов;
логин нормализуется в lowercase, IANA timezone проверяется runtime.

Argon2id: 19456 KiB, 2 прохода, parallelism=1, случайная соль библиотеки.
Основание: OWASP Password Storage Cheat Sheet; argon2 0.45.1 проверен через
npm metadata (Node >=16.17) и официальный репозиторий node-argon2.
Область: package.json, src/server/accounts.ts, createAccount.ts; lock отдельно.

Проверки: корректный/неверный ввод, соль/параметры/проверка пароля, отсутствие
plaintext в таблице/ответе, дубликат и запрет записи runtime; полный check.
