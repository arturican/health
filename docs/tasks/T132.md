# T132 — запуск и сборка API

Зависимость: T131. Продолжение явно запрошенного серверного хранения.

Результат: API запускается отдельным процессом на loopback, проверяет настройки
до открытия порта, завершается по SIGINT/SIGTERM. Production JS собирается отдельно
от dist. Неверная настройка или занятый порт дают ненулевой exit без утечки ввода.

Область: src/server/config.ts, runtime.ts, main.ts; package.json,
tsconfig.server.json; краткие инструкции, .env.example и игнорирование сборки.
Новые зависимости не нужны. Настройки БД вводятся при подключении БД.

Проверки: настройки (пропуск/границы/неверные значения), настоящий HTTP и
SIGTERM/SIGINT, занятый порт, полный npm run check, серверная сборка,
git diff --check. Frontend не переключается до готовности всего API.
