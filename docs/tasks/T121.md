# T121 — согласовать текстовый экспорт с байтовым лимитом

Основание: согласованные аудиты, QA-02 / AUD-02 / DATA-01. Зависимость: T120.

- Компактный экспорт не добавляет отступы, из-за которых принятые данные
  превышали 20 MiB; версия, строгая схема и лимит остаются прежними.
- Существующий тест 100000 продуктов использует синтетическое название
  кириллицей и проверяет повторное чтение, точный предел и лишний байт.
- Native Browser проверяет настоящий File, UTF-8, форматированный и компактный
  ввод, старые значения по умолчанию и граничный размер файла.
- Это не гарантия экспорта любого выросшего дневника: суммарные данные могут
  превысить лимит; нормализация старой копии тоже может увеличить её размер.

Область: domain/backup, существующий recordLimitBoundary, новый целевой
backupFile.browser test, TEST_CASES, карточка и статусы.
Проверки: RED на прежнем сериализаторе, targeted GREEN, `npm run check`,
`git diff --check`. Без зависимостей и изменений пользовательских данных.

Коммит: `fix(backup): T121 убрать отступы из текстового экспорта`.
