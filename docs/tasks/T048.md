# T048 — сравнение двух фотографий по датам

Зависимость: T047.

Наблюдаемый результат: сравнение двух фотографий по датам.

## Критерии

- Два независимо подписанных выбора фотографий показывают дату, подпись и изображение без обрезки/искажения; одинаковая запись вызывает понятную ошибку.
- Пустая/единственная запись и удаление выбранного фото обрабатываются без показа устаревших файлов.
- Сравнение не выдаёт диагноз или оценку состава тела; фото не отправляются наружу.
- Unit и настоящий browser проверяют выбор/замену/удаление, размеры, клавиатуру, 375 px и axe.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/PhotoComparison.tsx`, `src/pages/PhotosPage.tsx`, `src/styles.css`.
