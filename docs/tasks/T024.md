# T024 — Добавление еды в выбранный день дневника

Зависимость: T023.

Наблюдаемый результат: Добавление еды в выбранный день дневника.

## Критерии

- День меняется явным действием и сохраняется при переходах между разделами до перезагрузки.
- Форма записывает выбранный активный продукт/приём/массу/комментарий в открытый день.
- Ошибки и пустой каталог понятны; после сохранения форма очищается.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/DayContext.tsx`, `src/ui/DayPicker.tsx`, `src/pages/FoodForm.tsx`, `src/pages/NutritionPage.tsx`, `src/App.tsx`, `src/pages/FoodForm.test.tsx`, `src/ui/DayPicker.test.tsx`, `src/pages/ProductForm.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`.
