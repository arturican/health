# T156 — График анализов и история источников

Зависимость: T155. В разделе документов показываются выбор показателя,
график точных значений по датам, выбор измерения, единицы, референс как
на бланке, история и скачивание источника. Изменения базы обновляют график.
Сопоставимость методик проверяет пользователь; направление изменения
не объявляется улучшением/ухудшением, медицинские нормы не вычисляются.
Текст, знаки сравнения и неизвестные единицы остаются в истории.

Не больше 100 последних записей на графике и в его истории с явным счётчиком;
полные записи остаются в бланках. Файлы: DocumentsPage, LabTrends, lab-trends.css,
до 250 строк реализации. Распознавания нет.

Проверки: live-обновления, неизвестные данные, ошибка скачивания, E2E ручного
ввода/правки/удаления и скачивания исходных байтов, axe и узкий экран;
npm run check, визуальный просмотр, git diff --check. После коммита push всей
согласованной серии в origin/dev разрешён пользователем.

Коммит: `feat(labs): T156 добавить график показателей и историю источников`.
