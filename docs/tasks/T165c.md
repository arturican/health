# T165c — API журнала веса

Зависимость: T165b. История доступна только владельцу сессии; GET возвращает
не более 100 записей за запрос, убывающих по дате, с курсором before.
POST создаёт измерение; PUT/DELETE требуют текущую revision. Повторная дата
или устаревшая ревизия дают 409 без потери данных. Даты проверяются по timezone
аккаунта и дате рождения. Лимит записей соответствует формату резервной копии.

Область: weightRecords.ts, weightRoutes.ts, runtime.ts; HTTP/SQL тесты.
Проверки: CRUD, страницы, пустые данные, границы/некорректный ввод,
конкурентная правка, чужой владелец, повторный вход; npm run check, diff --check.
