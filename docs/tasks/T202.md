# T202 — Политика CSP для приложения

Зависимость: T201. Статус — только в TASKS.md.

Результат: CSP блокирует inline script, внешние соединения/фреймы/объекты; сохраняет локальные стили, графики и blob-preview. Browser/E2E работают с той же политикой, что Nginx.

Файлы/объём: deploy/nginx.conf, vite.config.ts; браузерные/конфигурационные тесты, DEPLOYMENT.

Проверки: Отрицательная браузерная проверка CSP; полный npm run check; Python deploy; локальный nginx и verify_build.

Один этап — один локальный коммит. Без push, деплоя, изменения реальных данных
и новых зависимостей; T205 требует отдельного разрешения по AGENTS.md.
