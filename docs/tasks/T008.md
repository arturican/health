# T008 — Локальная база и обработка ошибок раздела

Зависимость: T007.

Наблюдаемый результат: Локальная база и обработка ошибок раздела.

## Критерии

- Dexie version 1 создаёт metadata с ключом id; повторное открытие сохраняет записи.
- Транзакция с ошибкой не оставляет частично записанные данные.
- Тесты используют fake IndexedDB/отдельные имена; MODE=test выбирает health-diary-tests.
- Ошибка раздела показывает доступный fallback без содержимого записи; смена key восстанавливает компонент.

- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/db.ts`, `src/ui/StorageBoundary.tsx`, `src/App.tsx`, `tests/setup.ts`, `src/data/db.test.ts`, `src/ui/StorageBoundary.test.tsx`, `package.json`, `package-lock.json`.
