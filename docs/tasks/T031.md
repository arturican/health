# T031 — Сохранение итога шагов с уникальной датой

Зависимость: T030.

Наблюдаемый результат: Сохранение итога шагов с уникальной датой.

## Критерии

- Схема строгая: календарная дата и целое число 0–1 000 000 (технический предел, не медицинская рекомендация).
- По дате хранится одна запись; повторный ввод обновляет итог. Отсутствие возвращает null, явный ноль сохраняется.
- Будущий день и повреждённая запись отклоняются; миграция сохраняет предыдущие таблицы.
- Удаление записи идемпотентно, проверяет дату. Калории по шагам не вычисляются.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/activity.ts`, `src/data/db.ts`, `src/data/stepsRepository.ts`.
