# T277 — Профиль объёма пользовательской копии

Зависимость [T276](T276.md). Результат — числа, по которым можно воспроизвести
проверку переноса личного дневника. Профиль согласуется с владельцем до замеров.

1. Описать ожидаемый срок ведения дневника и количество записей по типам,
   сколько фото и документов, размеры и общий объём вложений. В качестве
   обычного сценария можно взять существующее 90-дневное синтетическое демо.
2. Определить один целевой профиль, который должен работать, и отдельный
   пограничный сценарий отказа. Указать среду испытания, включая браузер и
   подходящее устройство. Для граничной проверки ориентироваться на
   подтверждённые форматы и лимиты, размер в JSON и долю UTF-8/Base64.
3. Согласовать ожидаемый результат: скачивание, проверка файла, обратный
   импорт с сохранением записей, связей и байтов. Если нужен предел времени,
   согласовать его или записать время как измерение без порога.

Готово, когда область обещания записана числами в карточке и дополняет
BACKUP_CAPACITY. 20 МиБ текстового JSON, 200 МиБ полного JSON и 100 МиБ вложений
действуют вместе. Конкретный профиль в этих пределах всё равно нужно измерить.
`check:docs`, diff и один коммит с TASKS/PROGRESS.
