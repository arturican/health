# T277 — Профиль объёма пользовательской копии

Зависимость [T276](T276.md). 25.11.2026 владелец согласовал целевой профиль
полной копии на один год с 52 фото по 1 МиБ и 24 PDF по 2 МиБ.

## Синтетический набор для T278

365 дней включительно с 15.10.2025 по 14.10.2026 в часовом поясе Europe/Moscow.
Для записей используем правила [демо](../../src/server/demoText.ts) на 365 днях.
Фиксируем порядок дат с индексом от 0. Вес есть каждый третий день и в
последний день. Питание пропускается при остатке 5 от деления индекса на 19,
а день неполный при остатке 4 от деления на 13 или в последний день.
Полный день содержит 13 записей питания, неполный — 10. Шаги пропускаются
при остатке 6 от деления на 17, в одном дне указан ноль. Тренировки
записаны при остатке 1 от деления на 3. Три версии плана берутся по
индексам 0, 30 и 60, как в генераторе.

| Область | Количество |
|---|---:|
| Профиль | 1 |
| Измерения веса | 123 |
| Продукты | 15 |
| Записи питания | 4 417 |
| Отметки о питании | 346, из них 319 полных и 27 неполных |
| Дни с шагами | 343 |
| Тренировки | 122 |
| Версии плана | 3 |
| Геометрические JPEG, 960 × 720 | 52 по 1 048 576 байт |
| Синтетические PDF | 24 по 2 097 152 байт |
| Показатели с привязкой к PDF | 72, по 3 на документ |
| Файлы | 76, по одному на фото или документ |

Фото размещаются по индексам `7*n` при `n = 0…51`, документы — по индексам
`15*n` при `n = 0…23`. Генератор T278 создаёт валидные синтетические файлы
с разными байтами и фиксированными связями. Всего 104 857 600 байт вложений
(ровно 100 МиБ). Их Base64 занимает 139 810 304 байта полного JSON.
Остальное место в файле занимают UTF-8 записи, метаданные и структура JSON.
Фактический размер файла подтверждается в T278. Пределы форматов прежние:
20 МиБ для текстового JSON и 200 МиБ для полного.

## Приёмка в T278

- Локальные WSL Ubuntu 24.04 и PostgreSQL 18.3, отдельная тестовая БД и два
  синтетических аккаунта. Штатные проекты Playwright `chromium` (Desktop Chrome)
  и `mobile-chromium` (эмуляция Pixel 7, 375 × 812). Прогоны последовательные.
- Скачать полную копию из первого аккаунта, проверить файл и предпросмотр
  и восстановить во второй аккаунт. Сверить записи, связи и SHA256 каждого
  вложения. Проверить изоляцию владельцев и исходный аккаунт после операции.
- Записать размер скачанного JSON и время скачивания, предпросмотра и импорта
  для каждого проекта. Время служит измерением без порога приёмки.
- Для отказа использовать размер 209 715 201 байт (200 МиБ + 1).
  Проверить сообщение о размере файла в браузере и отсутствие запроса на
  импорт. Отдельно проверить HTTP 413 на `POST /api/v1/backup/full` с валидными
  заголовками и таким `Content-Length` через Fastify inject. Сверить содержимое
  дневника и ревизию с исходным снимком. API применяет лимит до разбора тела запроса.
