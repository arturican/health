# T187 — Проверить DNS и включить исходящий SMTP

Зависимость: T186. Пользователь добавил записи и поручил проверить их.
Результат: подтверждённые A/SPF/DKIM/DMARC/PTR и снятая задержка SMTP.

Область: deploy/check_mail.py, его Python regression-тест, почтовая конфигурация
и документация/статусы. Ошибка: Google DNS JSON возвращает TXT без внешних
кавычек, а проверка ошибочно превращает такой ответ в пустую строку.
Критерии: принимаются обычный и разбитый на quoted chunks TXT; неверная/отсутствующая
запись по-прежнему блокирует активацию; DKIM соответствует приватному ключу VPS;
до переключения очередь пуста и синтетическое письмо проверено/удалено.
После переключения defer_transports пуст, SMTP и DKIM только loopback,
TLS verify и фильтрация журналов сохранены; API и БД доступны.

Проверки: воспроизведение regression до исправления, Python deploy tests,
публичный DNS и opendkim-testkey на VPS, контроль служб/очереди,
полный npm run check, git diff --check. Настоящее письмо в ящик не отправляется
без согласованного тестового адреса; включение транспорта не выдаётся за
готовое восстановление пароля. Следующие задачи приложения не входят в T187.
