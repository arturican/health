# T171c — API документов

Зависимость: T171b2. Бинарный POST /documents сохраняет исходный PDF/JPEG/PNG/WebP
и карточку атомарно. GET списком/по id, PUT с revision; GET /:id/results-count.
DELETE требует revision и expectedResults: null разрешён только без показателей,
число должно совпадать с текущим количеством. Файл/карточка/показатели удаляются
одной транзакцией. UUID и хеш байтов защищают повтор загрузки.

Область: documentRecords.ts, documentRoutes.ts, runtime.ts, HTTP/SQL тесты.
Проверки: исходные байты, список/правка, подтверждение/конфликт удаления,
rollback, неверный ввод и чужой владелец; npm run check, diff --check.
