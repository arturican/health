# T057 — атомарное восстановление всей полной копии после согласия

Зависимость: T056.

Наблюдаемый результат: атомарное восстановление всей полной копии после согласия.

## Критерии

- API повторно проверяет unknown-копию и декодирует все вложения до RW-транзакции; результат предпросмотра не считается доверенным.
- Все 13 таблиц, включая настройки и байты файлов, заменяются одной RW-транзакцией. Поздняя ошибка откатывает весь дневник, пустые разделы удаляют соответствующие старые записи.
- Предпросмотр объясняет полную замену и отсутствие шифрования; восстановление доступно только после явного согласия. Новый файл и отмена сбрасывают согласие, pending блокирует повторный запуск и смену копии.
- Ошибка сохраняет прежнюю базу и предпросмотр для повтора, успех очищает предпросмотр и возвращает фокус. Unit/Chromium проверяют точные байты, все таблицы, reopen, откат и интерфейс.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/fullBackupRepository.ts`, `src/pages/FullBackupImport.tsx`.
