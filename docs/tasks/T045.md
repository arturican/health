# T045 — подготовка фотографий без EXIF с сохранением пропорций

Зависимость: T044.

Наблюдаемый результат: подготовка фотографий без EXIF с сохранением пропорций.

## Критерии

- Проверенный JPEG/PNG/WebP читается до декодирования: положительные размеры ≤32768 px, суммарно ≤64 млн пикселей, повреждённый заголовок отвергается.
- Геометрия без увеличения, длинная сторона ≤2048, размеры округляются до целых пикселей; слишком узкое изображение с короткой стороной после уменьшения <1 px отклоняется.
- createImageBitmap учитывает EXIF-ориентацию, canvas пересохраняет в JPEG quality0.9 на белом фоне (прозрачность заменяется белым).
- Выходной Blob повторно проходит проверку, пиксели декодируются; bitmap закрывается при успехе/ошибке, object URL не создаются.
- Unit проверяет геометрию/заголовки и ошибки; реальные браузерные фото-образцы проверяют размер, ориентацию, отсутствие EXIF и читаемость результата.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/imageGeometry.ts`, `src/domain/imageHeader.ts`, `src/media/preparePhoto.ts`, `docs/MVP.md`.
