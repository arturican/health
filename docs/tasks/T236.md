# T236 — Часовой пояс подтверждаемой регистрации

Зависимость: T235. IMP-005 / AUD-004. Статус — в TASKS.md.
Новая016 SQL migration (до250 строк, один файл приложения) добавляет nullable
registration_timezone к account_tokens и заменяет три auth-функции с прежними
сигнатурами. Часовой пояс меняется только при успешном подтверждении нового
email_required аккаунта, берётся из конкретного issued token. Cooldown,
generic resend, expiry/replay и блокировки владельца сохраняются.
Legacy/binding/reset/verified timezone не меняются анонимной регистрацией.
Старые миграции неизменны; выданные до016 ссылки без zone используют прежнюю
users.timezone. Откат приложения совместим с добавленным nullable полем,
откат схемы/данных — только по DEPLOYMENT/BACKUPS, без down поверх записей.

Регрессия: настоящий SQL/HTTP, синтетическая изолированная PostgreSQL,
повтор zone, cooldown, resend, expiry, гонки, legacy, upgrade015→016,
вход и граница дня. Письма перехватываются в памяти; внешнего SMTP нет.
Проверки: FAIL до изменения, связанные email/schema/migrations SQL+HTTP,
types/build:api/lint/docs/diff/staged review. Релиз требует fresh внешней
копии и миграции в составе отдельного backend release по runbook.
