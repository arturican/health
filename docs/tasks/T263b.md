# T263b — Повторяемая локальная среда

Зависимость: T263a. Результат: doctor/setup/API/UI/check команды на существующем
Node/npm/Docker, PostgreSQL 18.3 с постоянным именованным томом, отдельные
health и health_test. Windows поддерживается через WSL2 Ubuntu 24.04 x86_64;
native PowerShell для запуска скриптов не поддерживается.

Реализация: scripts/local.mjs, package.json, .env.example, .env.local.example
(до 250 строк изменений реализации). Нет новых npm-пакетов или Compose.
Docker уже требуется существующими backup/tests и используется локально;
это позволяет не добавлять установку/настройку системного PostgreSQL.

Критерии: машинные параметры отделены от четырёх DEV_* secrets; setup не
удаляет БД/том/аккаунты, не меняет существующие пароли и не принимает чужой
контейнер. Runtime работает только через health_app; миграции отдельно.
SMTP выключен; только синтетический local-demo. Внешние пути/пользователь
не зашиты в команды. Doctor проверяет версии, tools, Docker/image и конфиг.

Проверки: настоящая изолированная PostgreSQL на новых портах, повтор setup,
подсчёт/сохранность синтетических записей, readiness/auth, negative config,
ESLint/docs/diff/secret checks. Полный check/build:api после всей очереди.
