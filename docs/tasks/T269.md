# T269 — Единая проверка настроек разработки

Первый из четырёх шагов, согласованных 25.11.2026 после [T268](T268.md).
`restore`, `refresh` и локальный запуск одинаково проверяют четыре dev-пароля.
Шаблонные значения отклоняются до записи `.env` и отметки версии. Валидный
набор восстанавливается как раньше. Серверный SSH-помощник сохраняет независимую проверку.

Изменения в `scripts/secrets.mjs`, `scripts/local.mjs` и общем валидаторе.
Проверки: регрессия с подставным SSH, `test:local`, связанные проверки
локального SOPS при наличии инструментов, ESLint и `check:docs`.
