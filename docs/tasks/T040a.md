# T040a — текстовая копия всех дневников и энергетических планов

Зависимость: T040.

Наблюдаемый результат: текстовая копия всех дневников и энергетических планов.

## Критерии

- Новая текстовая копия включает шаги, тренировки и версии планов; старые v1 без этих массивов читаются как пустые массивы.
- Даты/ID/ревизии уникальны по модели; планы проходят семантическую проверку снимка/метода до записи, будущая дата начала плана допустима.
- Экспорт согласованно читает все текстовые таблицы и отвергает лишний профиль; restore заменяет их одной транзакцией с откатом при сбое.
- Предпросмотр явно показывает количество новых записей и область замены. Отсутствующие в старой копии массивы восстанавливаются пустыми.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/backup.ts`, `src/data/backupRepository.ts`, `src/pages/SettingsPage.tsx`.
