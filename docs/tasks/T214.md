# T214 — Контракт и итоговая приёмка backend

Зависимость: T213. Статус — в TASKS.md.

Результат: API_REFERENCE для существующих групп маршрутов: методы/пути,
доступ/форматы тела и служебных заголовков, пагинация/ревизии/ошибки,
файлы/копии и liveness/readiness. Примеры исключительно синтетические.
BACKEND_PLAN фиксирует выполненный объём, доказательства и границы готовности.
PROJECT_MAP направляет к актуальному контракту, исторические MVP/DB-спецификации
не выдаются за актуальный список реализованного API.

Критерии: маршруты сопоставлены runtime/Routes/client и существующим тестам,
готовность текущих восьми экранов отделена от IDEAS и внешнего watchdog.
Последние полные gates T213 записаны без повторения неизменённого кода;
npm run check:docs и git diff --check проходят после документации.
Новые функции, Swagger-зависимости, медицинские формулы, push/деплой не нужны.
Файлы только документации. Один локальный коммит, затем остановка очереди.
