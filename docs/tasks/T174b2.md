# T174b2 — Смена аккаунта между вкладками

Зависимость: T174b. Успешный ответ защищённого API содержит X-Account-Id;
клиент сверяет его до чтения тела. Bootstrap сверяет владельца diary-state
с ответом входа. Вкладки уведомляются о login/logout через BroadcastChannel
без передачи записей, токенов или логина. При недоступном канале проверка
ответа продолжает защищать запросы. Старый bootstrap не блокирует новый вход.

Область: server/auth.ts, client/http.ts, client/auth.ts,
client/AuthBoundary.tsx, client/accountChanges.ts.
Проверки: регрессия чужого/отсутствующего владельца, заголовки реального API,
повтор bootstrap, события вкладок/cleanup; npm run check, diff --check.
