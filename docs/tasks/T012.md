# T012 — Редактирование профиля без изменения истории веса

Зависимость: T011.

Наблюдаемый результат: Редактирование профиля без изменения истории веса.

## Критерии

- Форма редактирования заполняется сохранёнными параметрами, без полей первого измерения.
- Сохранение и отмена не меняют историю веса; необязательные поля можно очистить.
- Дата рождения не может быть позже уже сохранённого измерения; ошибка не меняет базу.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/profileRepository.ts`, `src/pages/ProfilePage.tsx`, `src/data/profileRepository.test.ts`, `src/pages/ProfilePage.test.tsx`, `src/pages/ProfilePage.browser.test.tsx`.
