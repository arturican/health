# T172e — Подтверждённое удаление дневника

Зависимость: T172d5. DELETE /api/v1/diary требует сессию, Origin/CSRF,
ключ повтора, generation/changeRevision и явное подтверждение в JSON.
Атомарно удаляет записи, файлы, метаданные и прежние команды владельца,
сбрасывает настройки и меняет generation. Аккаунт и сессии сохраняются.

Область: clearRoutes.ts, runtime.ts, writeCommand.ts, importRequest.ts.
Проверки: заполненный/пустой дневник, повтор, устаревшие запросы и подтверждения,
валидация/доступ, другой владелец и rollback; npm run check, diff --check.
