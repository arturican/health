# T254c — Независимые offsite alerts

Blocked до выбора транспорта T252a. После T254b связать offsite_check с
независимой доставкой на frontend VPS: hourly timer, приватный durable state,
дедупликация и recovery, неизменная retention 7/14, безопасный rollback.
Не использовать data VPS как единственный SMTP relay.

В отдельной малой задаче подготовить state/delivery артефакт после выбора
конкретного канала. Приёмка: синтетические missing/corrupt вызывают полученное
оповещение, healthy — recovery; SMTP failure не подтверждает доставку,
повтор не спамит, payload без имён архивов/hash/данных. Доказательство receipt
требует наблюдаемого независимого канала, а не только exit 0 SMTP.
