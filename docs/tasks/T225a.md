# T225a — Фокус после отмены при устаревших данных

Зависимость: T225. Статус — в TASKS.md.
P2 a11y: current=false отключает кнопку строки; отмена Confirmation не может
вернуть на неё фокус. Общая Confirmation должна возвращать его на прежнюю
доступную кнопку либо на доступный main, когда кнопка удалена/отключена.
Не отбирать фокус после успешного удаления у явной логики родителя.
Файлы: Confirmation и регрессионный тест; docs/TASKS/PROGRESS.
Проверки: unit focus с реальным disabled opener, связанные Browser/E2E,
lint/types/docs/diff. Один коммит; затем T226.
