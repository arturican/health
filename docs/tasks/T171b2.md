# T171b2 — API фотографий

Зависимость: T171b1. POST /photos принимает подготовленный JPEG бинарно,
X-Record: id/fileId/date/title/note/mime. Размеры определяет декодер. Карточка,
файл и команда сохраняются атомарно; UUID карточки защищает повтор с хешем байтов.
GET — страницы UUID, PUT меняет подпись/дату/заметку с revision, DELETE удаляет
файл и карточку. JPEG нужен для совместимости полной копии v1.

Область: photoRecords.ts, photoRoutes.ts, runtime.ts, HTTP/SQL тесты.
Проверки: CRUD/скачивание, страницы, повтор, rollback, границы и чужой доступ;
npm run check, diff --check.
