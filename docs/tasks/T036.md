# T036 — Оценка расхода в покое по Mifflin–St Jeor

Зависимость: T035.

Наблюдаемый результат: Оценка расхода в покое по Mifflin–St Jeor.

## Критерии

- Формула/источник/единицы/границы добавлены в CALCULATIONS до реализации.
- Чистая функция валидирует неизвестный ввод; отсутствующие данные/none/возраст вне 19–78 дают null.
- Недопустимые параметры дают ошибку, неположительная оценка недоступна; примеры 1617,5 и 1451,5 подтверждены.
- Промежуточное округление, активность и калорийная цель отсутствуют в этом расчёте.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/restingEnergy.ts`, `docs/CALCULATIONS.md`.
