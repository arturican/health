# T054a — правка и удаление отдельных показателей

Зависимость: T053. Часть разрешённого полного локального MVP.

## Критерии

- Редактор сохраняет ID/документ-источник, проверяет все поля/тип/знак, позволяет менять число/текст, дату, единицы/референс/заметку без изменения оригинального файла.
- Отсутствующий показатель/источник, изменение documentId и неверный ввод отклоняются; транзакции откатываются при отказе.
- Удаление отдельного показателя требует подтверждения, оставляет документ/соседние показатели целыми. Отмена сохраняет всё.
- Контекст источника блокируется при правке/сохранении/подтверждении; ошибки сохраняют редактор, фокус возвращается в форму/список/подтверждение.
- Unit/Chromium подтверждают редактор, отмену, удаление, ошибки, точность/байты, клавиатуру и 375 px/axe/no HTTP.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/data/labRepository.ts`, `src/pages/LabForm.tsx`, `src/pages/LabList.tsx`, `src/pages/LabSection.tsx`.
