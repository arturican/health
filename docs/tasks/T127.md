# T127 — стабильный фокус после асинхронных изменений

Зависимость: T126. Пользователь попросил устранить замеченную локально
нестабильность тестов фокуса.

## Результат

Редактирование веса сохраняет фокус на дате даже при действии сразу после
загрузки формы. Тесты полного восстановления ожидают перенос фокуса эффектом.

## Объём

- Воспроизвести гонку начала правки веса отдельным regression-тестом.
- Исправить перенос фокуса в WeightPage, если гонка подтверждается.
- Ожидать асинхронный фокус в FullBackupImport.test.tsx.
- Не добавлять задержки, retries, зависимости и увеличенные таймауты.

## Проверки

- Regression-тест падает до исправления и проходит после него.
- Повторные прогоны RecordFocus и FullBackupImport проходят без retries.
- `npm run check` и `git diff --check` проходят.
- Ручной сценарий: начать и отменить правку веса; фокус на дате и затем весе.

Коммит: `fix(focus): T127 устранить гонку фокуса при правке веса`
