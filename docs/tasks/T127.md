# T127 — спроектировать переход к серверному хранению

Зависимость: T126. Запрос пользователя: хранить данные на новом VPS, отдельные
аккаунты; сайт оставить на прежнем VPS. Настройку нового сервера выполнить позже
из локального терминала пользователя.

Результат — [SERVER_STORAGE.md](../SERVER_STORAGE.md): архитектура, границы
авторизации, PostgreSQL/вложения, контракты владельцев/дат/чисел, миграция
существующих дневников, резервирование, тесты и небольшие последующие этапы.
Текущее хранение и публикация не переключаются. Не нужны установка зависимостей,
SSH, изменение VPS или загрузка медицинских данных.

Проверки: соответствие текущим моделям/репозиториям/CI, `npm run check:docs`,
`git diff --check`, проверка staged diff на секреты. Runtime не меняется.
Обновить TASKS и PROGRESS; отдельный локальный коммит.
