# T046a — атомарное сохранение фото и локальный предпросмотр

Зависимость: T045.

Наблюдаемый результат: атомарное сохранение фото и локальный предпросмотр.

## Критерии

- Фото имеет дату, подпись/заметку, UUID, fileId и действительные подготовленные размеры ≤2048; будущая дата/неизвестные поля отвергаются.
- Подготовка JPEG без EXIF идёт до RW; файл и карточка записываются одной транзакцией с общим лимитом вложений и откатом при отказе.
- Версия DB10 добавляет photos с уникальным fileId, сохранённые таблицы остаются доступными; история сортируется по дате/ID.
- FileImage показывает только текущий fileId, generic-ошибки не раскрывают содержимое. URL освобождаются при замене/unmount, поздний ответ не показывает старый файл.
- Unit/browser подтверждают атомарность и настоящий Blob/изображение, сохранность после reopen, ошибки и отсутствие внешних запросов.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/photo.ts`, `src/data/photoRepository.ts`, `src/data/db.ts`, `src/ui/FileImage.tsx`, `src/styles.css`.
