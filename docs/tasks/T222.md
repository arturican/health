# T222 — Финальная приёмка, push и проверенный релиз

Зависимость: T226 (после HTTPS-приёмки T222a). Статус — в TASKS.md.

P1. Предыдущая публикация подтверждает T215, но не новую очередь исправлений.

Результат и критерии:
После последних изменений полный check, build:api, deploy gates и review.
Push dev без force; API-артефакт из проверенного коммита, свежая внешняя копия,
SHA256/права/атомарное переключение с откатом при ошибке. Успешный CI/deploy и
точный release SHA; deployed desktop/mobile, формы/CRUD/reload/выход,
реальные API/auth/валидация/сервисы и безопасные логи. Исходные данные сохранены.

Документы приёмки/релиза, TASKS/PROGRESS. Не менять схему, секреты, SMTP,
retention или сторонние сервисы. Проверка на отдельном синтетическом demo;
реальные письма не отправлять. Блокирующие failures запрещают деплой.
Один итоговый коммит; после его push проверить CI и фактический frontend SHA.
Отдельный коммит, затем следующий согласованный этап.
