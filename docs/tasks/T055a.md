# T055a — полный формат и кодирование файлов

Зависимость: T054b. Часть разрешённого полного локального MVP.

## Критерии

- JSON health-diary-full v1 содержит text (проверенную текстовую копию восьми разделов), metadata, photos, documents, labResults и files с Base64/UUID/purpose/MIME/size.
- Строгая проверка версии/полей/дат/значений/уникальных ID, fileId, documentId, единственного владельца каждого файла; фотографии требуют JPEG, metadata каталога соответствует done.
- Base64 кодируется ограниченными чанками без переполнения стека, декодирование проверяет канонические символы/padding/длину и size ≤20 MiB до чтения; общий предел файлов 100 MiB.
- Полная копия ограничена 200 MiB UTF-8; ошибки не содержат личных данных. Здесь проверяются формат/связи; байты/декодирование изображений до импорта — T056.
- Unit/Chromium проверяют кодек, границы чанков, двоичные/Unicode данные, испорченные поля/связи/размеры и отсутствие внешних запросов.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/domain/base64.ts`, `src/domain/fullBackup.ts`.
