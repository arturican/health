# T061a — точное отображение исходных дробных значений

Зависимость: T060.

Наблюдаемый результат: точное отображение исходных дробных значений.

## Критерии

- Рост, исходные значения продукта, масса порции и ручная длительность/расход тренировки показываются без неявного округления или превращения малого положительного числа в ноль.
- Общий чистый formatter использует русскую десятичную запятую, не группирует цифры и сохраняет значащую точность Number; неизвестные значения остаются неизвестными.
- Расчётные итоговые калории/БЖУ/оценки сохраняют явно описанное округление, сами записи и расчёты не меняются.
- Unit проверяет обычные, дробные и крайние finite значения; Chromium вводит значения через реальные формы и проверяет профиль/каталог/запись еды/тренировку и reload на 375 px.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/exactNumber.ts`, `src/pages/ProfilePage.tsx`, `src/pages/ProductCatalog.tsx`, `src/pages/FoodJournal.tsx`, `src/pages/WorkoutJournal.tsx`.
