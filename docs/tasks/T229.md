# T229 — Параллельные проверки GitHub Actions

Зависимость: T227. Статус — в TASKS.md.

Запрос 20.10.2026: сократить время GitHub Actions. Последние завершённые
запуски занимали 8:40–9:02: последовательный npm run check, примерно
2:38 coverage и 3:24 E2E. Реализация ограничена CI, приложение не меняется.

Результат: независимые проверки выполняются параллельно; desktop и mobile
E2E используют отдельные PostgreSQL/API с прежним workers: 1. Один frontend
build передаётся по неизменяемому ID артефакта обоим E2E и deploy.
Итоговый check успешен только после успеха всех обязательных jobs.

Критерии:
- Сохранены docs, strict lint/types, coverage thresholds, Native Browser,
  все desktop/mobile E2E, Python deploy, systemd и production archive gates.
- E2E не делят API/БД/часы/backup slot; оба проекта дают отчёты независимо.
- Build доступен E2E для push/PR dev/master и ручного запуска; deploy разрешён
  только после всех gates для push/workflow_dispatch dev, как прежде.
- Один и тот же dist проверяется и публикуется; rebuild в E2E/deploy отсутствует.
- Пропуск/отмена/ошибка обязательного job не дают успешный check или deploy.
- Закреплённые SHA actions, permissions, secrets и concurrency dev сохранены.

Файлы: .github/workflows/check.yml, docs/TESTING.md, docs/PROJECT_MAP.md,
docs/DEPLOYMENT.md, эта карточка, TASKS.md и docs/PROGRESS.md.
Один файл реализации, до 250 добавленных/удалённых строк; зависимости не меняются.
Проверки: actionlint из временного каталога, разбор YAML и графа gates,
отрицательные сценарии итогового check, все команды фаз локально,
обе выборки E2E, deploy/archive/unit gates, docs/diff/staged review.
Логи вне Git. Один локальный коммит; push/деплой не разрешены этим запросом.
Удалённое ускорение — оценка до первого разрешённого запуска нового workflow.
