# T032 — Ввод и подтверждённое удаление шагов выбранного дня

Зависимость: T031.

Наблюдаемый результат: Ввод и подтверждённое удаление шагов выбранного дня.

## Критерии

- Реальные клики сохраняют ноль и обновляют итог выбранной даты; выбранный день общий с питанием.
- Пустое/дробное/отрицательное/слишком большое значение вызывает связанную с полем ошибку и фокус, не меняя запись.
- Удаление требует подтверждения; отмена сохраняет данные. После удаления поле очищается.
- Данные сохраняются после remount; мобильный экран и axe проходят, ошибка хранения допускает повторный ввод.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/ActivityPage.tsx`, `src/pages/StepsForm.tsx`, `src/App.tsx`.
