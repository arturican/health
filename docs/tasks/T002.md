# T002 — строгие правила ESLint

Зависимость: T001. Результат: код и тесты проверяются линтером вместе с существующими
типами, тестами и сборкой.

## Критерии

- Совместимые точные версии ESLint, TypeScript ESLint и правил React.
- Запрет явного `any` и обходов проверки типов; правила hooks и доступности JSX.
- Конфигурация охватывает src, тесты и конфигурационные файлы, исключает артефакты.
- `npm run lint` добавлен в `npm run check`; весь check проходит.
- Проверено, что нарушение выбранного правила приводит к ошибке lint.

Не добавлять бизнес-функции. Коммит: `chore(quality): T002 add strict lint rules`.
