# T013 — Репозиторий истории веса с уникальной датой

Зависимость: T012.

Наблюдаемый результат: Репозиторий истории веса с уникальной датой.

## Критерии

- Повторное сохранение той же даты обновляет вес, сохраняя ID и одну запись.
- Изменение даты не затирает другое измерение; ошибка откатывает запись.
- Выбор последнего веса ограничен указанной датой; отсутствие возвращает null.
- Future-даты, даты раньше рождения, повреждённые данные и неизвестные поля отклоняются.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/weightRepository.ts`, `src/data/weightRepository.test.ts`.
