# T171a — серверная проверка содержимого вложений

Зависимость: T170. Проверка байтов повторяет контейнер/MIME/размер из domain;
sharp декодирует JPEG/PNG/WebP с существующим пределом 64 млн пикселей.
Фото после клиентской подготовки не больше 2048 px. PDF проверяется как
контейнер по существующим правилам, без OCR, исполнения или обещания антивируса.
Байты принятого файла не меняются.

Область: attachmentValidation.ts, package.json/lock, тесты и DEPENDENCIES.
sharp 0.35.5 проверен по официальным docs и npm engines >=20.9.0 для Node24.
Проверки: настоящие синтетические изображения, MIME/обрезка/повреждение,
размеры/назначение/PDF, npm audit, npm run check и diff --check.
Коммит: feat(api): T171a проверять содержимое вложений на сервере
