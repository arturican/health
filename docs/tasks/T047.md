# T047 — редактирование и подтверждённое удаление фото

Зависимость: T046b.

Наблюдаемый результат: редактирование и подтверждённое удаление фото.

## Критерии

- Правка даты/подписи/заметки сохраняет fileId, размеры и байты; неизвестная/будущая дата, отсутствующая карточка и чужие поля отвергаются.
- Подтверждённое удаление удаляет фото и его файл одной RW-транзакцией; поздний отказ откатывает обе записи. Отмена сохраняет данные.
- Ошибка сохраняет редактор; действия блокируются при сохранении/удалении. Фокус возвращается в доступную форму/заголовок после завершения.
- Unit и реальные browser-клики проверяют сохранность файла, редактор, отмену и подтверждение, атомарность и 375 px/axe.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/photoRepository.ts`, `src/pages/PhotoForm.tsx`, `src/pages/PhotoGallery.tsx`, `src/pages/PhotosPage.tsx`.
