# T039 — независимые расчёты цели, расхода и баланса

Зависимость: T038.

Наблюдаемый результат: независимые расчёты цели, расхода и баланса.

## Критерии

- Общий расход: ручное значение или снимок покоя × пользовательский коэффициент; активность дополнительно не прибавляется.
- Остаток цели = цель − внесённая еда, суточный баланс = расход − питание только при подтверждённом полном дне.
- Неизвестные значения дают null, явный ноль сохраняется; вычисления не округляются. Неверный ввод отклоняется до расчёта.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/energy.ts`, `docs/CALCULATIONS.md`.
