# T021 — Создание собственного продукта через форму

Зависимость: T020.

Наблюдаемый результат: Создание собственного продукта через форму.

## Критерии

- В разделе питания доступна форма, ошибки связаны с полями и фокусом.
- Пустые БЖУ сохраняются как null, явный 0 остаётся 0, числа принимают запятую.
- Сохранение очищает форму; ошибка хранилища оставляет ввод для повторения.
- Примеры добавляются кнопкой, не автоматически.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/ProductForm.tsx`, `src/pages/NutritionPage.tsx`, `src/App.tsx`, `src/pages/ProductForm.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`.
