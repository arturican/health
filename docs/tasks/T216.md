# T216 — Аудит завершённости рабочей версии

Зависимость: T215. Статус — в TASKS.md.

Запрос 20.10.2026 разрешает завершение существующего продукта, рефакторинг,
обновление инструкций, проверки, push dev и штатный деплой с сохранением данных.
Новые продуктовые идеи не входят в объём.

Результат: единая матрица обязательных функций и проверяемых критериев в
REFACTORING_PLAN.md; подтверждённые дефекты и работы имеют карточки и статусы
в TASKS. Изучить собственный клиентский/серверный код, данные, тесты,
конфигурацию и доставку; исключить зависимости и сгенерированные результаты.
Review частей текущего аудита можно делегировать без параллельной реализации.

Критерии: чистота/ветка/remote зафиксированы; исходный npm run check,
build:api и deploy gates выполнены, ошибки отделены от новых регрессий;
заглушки, дублирование и неиспользуемый код проверены по вызовам;
обязательный объём отделён от IDEAS. Не приравнивать план к реализации.

Файлы: эта карточка, REFACTORING_PLAN, карточки найденных работ, TASKS/PROGRESS.
Проверки документации: npm run check:docs, git diff --check. Один коммит.
Далее последовательно выполнять подтверждённые задачи и выпуск.
