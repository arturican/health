# T029 — Проверка текстового импорта и предварительный просмотр

Зависимость: T028.

Наблюдаемый результат: Проверка текстового импорта и предварительный просмотр.

## Критерии

- JSON UTF-8 до 20 MiB проверяется до обращения к базе; ошибки не выводят содержимое файла.
- Версия и поля строгие; ID и даты в своих таблицах уникальны, даты не в будущем, связи еды и история веса согласованы.
- Предпросмотр показывает область замены и количество записей; проверка и отмена ничего не сохраняют.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/backup.ts`, `src/data/backupRepository.ts`, `src/ui/backupFile.ts`, `src/pages/SettingsPage.tsx`.
