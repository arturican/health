# T034 — Добавление тренировок и журнал выбранного дня

Зависимость: T033.

Наблюдаемый результат: Добавление тренировок и журнал выбранного дня.

## Критерии

- Пользователь вводит вид/длительность, необязательные ккал/источник/комментарий; данные сохранены для выбранного дня.
- Пустые ккал остаются null, ноль показывается явно; нескольких тренировок в день разрешено.
- Ошибки связаны с полем и переводят фокус; сбой хранения оставляет ввод для повтора.
- Реальные браузерные клики, смена дня, remount, mobile/axe проходят; редактирование и удаление остаются T035.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/WorkoutForm.tsx`, `src/pages/WorkoutJournal.tsx`, `src/pages/ActivityPage.tsx`.
