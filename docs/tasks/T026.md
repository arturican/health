# T026 — Итоги питания и явная полнота дня

Зависимость: T025.

Наблюдаемый результат: Итоги питания и явная полнота дня.

## Критерии

- Итоги суммируют порции снимков, неизвестный макронутриент делает свой итог неизвестным.
- Пустой неполный день — нет данных; явно полный пустой день — 0.
- Полнота хранится отдельно на дату, переключается обратно и переживает перезагрузку.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/nutrition.ts`, `src/data/db.ts`, `src/data/nutritionRepository.ts`, `src/ui/NutritionSummary.tsx`, `src/pages/NutritionPage.tsx`, `src/domain/nutrition.test.ts`, `src/data/nutritionRepository.test.ts`, `src/ui/NutritionSummary.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`, `docs/CALCULATIONS.md`.
