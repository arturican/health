# T134 — мобильная версия главной страницы в Figma

Зависимость: T133. Пользователь явно разрешил продолжить главную Desktop
и сделать её мобильную версию; отдельный экран восстановления пароля не нужен.

## Результат

Один редактируемый экран «Сегодня · Mobile 390» в том же Figma-файле,
с содержимым и токенами завершённого Desktop-концепта T133.
Работа начинается после завершения и проверки T133.

## Критерии

- Ширина 390 px, вертикальная компоновка с Auto Layout; заголовки, карточки,
  показатели и действия остаются читаемыми без горизонтального переполнения.
- Доступны выбор даты, запись веса, переход к питанию и разделам дневника.
  Навигация адаптирована для телефона, области действий не меньше 44×44 px.
- График перестроен под узкую ширину, даты и единицы читаемы; значения
  соответствуют синтетическим данным Desktop, отметка «Демо» сохранена.
- Повторные элементы — экземпляры компонентов; тексты и графика редактируемы.
  Исходные примеры и Desktop не изменяются ради мобильной компоновки.
- Проверены типы узлов, шрифты, размеры, контраст, отсутствие наложений
  и растрового изображения полного UI; просмотрен итоговый скриншот.
- Ссылка на frame и фактические проверки записаны в PROGRESS.md;
  `npm run check:docs` и `git diff --check` проходят.

Код приложения, новые продуктовые функции и полный набор состояний не входят
в задачу. После T134 остановиться; перенос в приложение отдельно не разрешён.

Коммит: `docs(design): T134 создать мобильный концепт главной в Figma`.
