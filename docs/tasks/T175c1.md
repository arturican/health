# T175c1 — Чтение файлов и независимая подготовка

Зависимость: T175b. GET файла сообщает purpose в защищённом ответе; клиент
проверяет метаданные и сигнатуру, отдаёт Blob только текущему аккаунту.
Подготовка файла вынесена из IndexedDB-репозитория в media без изменения
поведения; старый экспорт сохранён для локального адаптера и тестов.

Область (5 файлов): server/fileRecords, client/fileRepository, media/prepareFile,
media/prepareDocument, data/fileRepository. Проверки: байты PDF, purpose,
404/другой владелец/нет сессии, повреждённое тело, существующая подготовка файлов.
npm run check, diff --check.
