## Результат

App.tsx/runtime/nginx подтверждают React SPA с восемью экранами и серверным
хранением/API. Frontend159.194.208.200 раздаёт HTML/JS/CSS и проксирует /api/
через loopback tunnel к Fastify/PostgreSQL на2.26.54.81. API health/readiness
прошли публичную read-only проверку на6cceabd; закрытый diary требует auth.
Это не live CRUD и не доказательство посещаемости, возраста проекта или
нахождения всех компонентов в конкретном Beget account. Разделение хостов
сохраняется в подготовленном тексте поддержки.

Официальная статья Beget описывает PTR через тикет; из неё не следует
безусловное предоставление PTR или исключение из полученного отказа.
Рекомендуемый следующий шаг — попросить поддержку рассмотреть фактическое
приложение и уточнить требования к размещённому frontend/API proxy.
При повторном отказе — выбрать существующий независимый authenticated SMTP
submission relay вне data VPS отдельной карточкой/доступом; провайдер/тариф/
учётные данные пока не выбраны, транспорт не реализован и не проверен.
Такой выбор потребует проверки sender/auth/domain/DNS/TLS/privacy gates,
не простого отключения текущего PTR gate. Relay через data VPS не покрывает
его полный отказ и не является решением AUD-011.

Standalone frontend SMTP остаётся deferred/disabled на boot по T262a;
текущую remote конфигурацию эта задача не меняет. T262/T253a/T254c blocked,
