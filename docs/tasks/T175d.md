# T175d — Настройки, копии и удаление через API

Зависимость: T175c2. Подтверждение хранит свежие generation/changeRevision
и контекст входа, захваченные до предпросмотра. Замена/очистка требуют его
в HTTP-заголовках. Экспорт валидируется; повтор больших команд определяется
SHA-256 тела. Успех атомарно публикует новое состояние и сообщение для нового UI.

Область (5 файлов): confirmations, visibilityRepository, backupRepository,
notices, QueryFeedback. Проверки PostgreSQL: экспорт/восстановление текстовых
данных и PDF/флагов, stale confirmation, повтор после потерянного ответа,
очистка без удаления аккаунта, исходные revision и сообщения после смены контекста.
npm run check, diff --check.
