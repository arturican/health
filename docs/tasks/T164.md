# T164 — профиль, вес и RLS

Зависимость: T163b. Таблицы profiles/weights используют владельца, ограничения
чисел/дат, уникальную дату измерения внутри аккаунта, revision и timestamps.
RLS default deny, FORCE; владельца задаёт API внутри транзакции.

Область: migrations/003_profile_weight.sql, src/server/userTransaction.ts.
Для записи транзакция блокирует аккаунт advisory lock; чтение использует
repeatable read. Контекст user_id/timezone локален транзакции.

Проверки: два аккаунта через runtime-роль, чтение/изменение/удаление чужого,
FK/check/unique, маленькие числа, rollback и повторное использование pool,
полный npm run check; git diff --check.
