# T182 — Ограниченное создание аккаунта

Зависимость: T181. Согласованы T182–T185, тесты, отдельные коммиты, push и deploy.
Результат: runtime создаёт аккаунт только через фиксированную SQL-функцию;
прямые INSERT/UPDATE/DELETE пользователей остаются запрещены.

Файлы: migrations/011_registration.sql, src/server/registration.ts и тесты.
Критерии: Argon2id; нормализация логина; уникальность при конкуренции; повтор
не меняет существующий аккаунт; неверный ввод не записывается. SECURITY DEFINER
имеет фиксированный search_path и EXECUTE только у runtime и владельца.
Проверки: PostgreSQL integration, полный npm run check, git diff --check.
Официальное основание: [CREATE FUNCTION](https://www.postgresql.org/docs/18/sql-createfunction.html).
