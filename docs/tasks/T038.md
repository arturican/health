# T038 — Настройки цели и способа оценки расхода с историей версий

Зависимость: T037.

Наблюдаемый результат: Настройки цели и способа оценки расхода с историей версий.

## Критерии

- Пользователь задаёт необязательную цель и один способ расхода, дату >=сегодня и источник; данные сохраняются новой версией.
- Пустая цель/null, явный ноль и ручная оценка/коэффициент независимы; поля другого метода не сохраняются.
- История показывает дату действия, цель, способ, неизменяемый снимок и ограничения формулы, без предположения пола/коэффициента.
- Ошибки связаны с полем, фокус после сохранения возвращается в дату; сбой хранения оставляет ввод. Browser/mobile/axe проходят.
- Ошибка чтения плана не блокирует управление резервной копией в остальных настройках.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/EnergyPlanForm.tsx`, `src/pages/EnergyPlanSettings.tsx`, `src/pages/SettingsPage.tsx`.
