# T217 — Сохранение черновика тренировки

Зависимость: T216. Статус — в TASKS.md.

P2. WorkoutJournal не знает о pending дочернего WorkoutForm: при медленном
сохранении смена редактора размонтирует форму и скрывает черновик/ошибку.
Удаление не блокирует новую запись.

Результат и критерии:
Согласовать disabled/onPendingChange и общий busy по существующему образцу
FoodJournal. Отказ сохраняет поля и видимую ошибку, повтор сохраняет ровно
одну тренировку; во время удаления форма недоступна и сохраняет черновик.

src/pages/WorkoutJournal.tsx, WorkoutForm.tsx; отдельные регрессионные тесты.
Проверки: тест сначала воспроизводит дефект, затем целевые unit/browser/E2E,
lint/types, docs/diff. Полный check всей очереди перед push.
Отдельный коммит, затем следующий согласованный этап.
