# T128 — фокус после отмены полной копии

Зависимость: T127. При разрешённом push T127 CI выявил потерю фокуса после
отмены предпросмотра. Исправление завершает публикацию согласованной задачи.

## Результат

Отмена возвращает фокус полю файла после удаления предпросмотра, включая
отмену до завершения пассивного эффекта заголовка.

## Объём и проверки

- Воспроизводящий тест ранней отмены падает до исправления и проходит после.
- Возврат фокуса выполняется после обновления DOM, без задержек и retries.
- `npm run check`, `git diff --check`; затем разрешённый push и CI/CD.

Коммит: `fix(focus): T128 вернуть фокус после отмены предпросмотра`
