# T128 — изолированный API factory

Зависимость: T127. Первый независимый локальный этап серверного хранения,
пока настройка VPS отложена пользователем.

- Добавить Fastify factory в src/server; GET /api/v1/health — только liveness.
- Общие ответы no-store/nosniff; неизвестные маршруты не раскрывают URL.
- Неверный JSON/тип/большое тело и неожиданные ошибки возвращают безопасные
  сообщения без исходного ввода, cookies, токенов или stack trace.
- Не логировать запросы, не доверять произвольным proxy headers; ограничить
  тело и таймауты. Дневники, БД, аккаунты и frontend не подключать к этому factory.
- Один новый runtime-пакет: точный Fastify 5.12.7 из официального npm, версия
  проверена до установки. PostgreSQL/ORM/плагины авторизации пока не нужны.

Область runtime: package.json и src/server/app.ts; lock автоматически.
HTTP injection tests в Node через тот же Vitest/coverage, рядом с реализацией;
новый runner не нужен. Конфигурацию существующих gates не ослаблять.

Проверки: targeted server test, lint/types, npm audit, полный npm run check,
Python-тесты установщика, production bundle не включает Fastify, diff/secret review.
Описать точный статус в SERVER_STORAGE, DEPENDENCIES, TESTING, TASKS/PROGRESS.

Коммит: `feat(api): T128 добавить изолированный каркас серверного API`.
