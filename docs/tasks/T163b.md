# T163b — HTTP-авторизация

Зависимость: T163a. Результат — login/session/logout с Secure HttpOnly
SameSite=Lax __Host-cookie, no-store, обязательным Origin и CSRF для изменений.
Нет произвольного CORS или доверия клиентскому X-Forwarded-For.

Лимиты: 30 попыток/IP за минуту, 5/логин за 15 минут, до 4 одновременно;
память ограничена. Сброс счётчиков при рестарте процесса — известное ограничение.
Production требует DATABASE_URL и HTTPS APP_ORIGIN; API отвергает повышенные
права соединения. Локальный запуск без БД сохраняет только liveness.

Область: auth.ts, httpSecurity.ts, loginLimit.ts, config.ts, runtime.ts.
Проверки: настоящая БД/runtime; cookie/rotation/logout, Origin/CSRF, no-store,
неверные реквизиты, границы лимита, конфигурация, полный npm run check.
Коммит: feat(auth): T163b подключить защищённые маршруты авторизации
