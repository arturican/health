# T171b1 — защищённые файлы и бинарный транспорт

Зависимость: T171a. GET /files/:id отдаёт байты только владельцу, no-store,
nosniff, attachment и sandbox CSP. Общий helper вставки проверяет квоты в write-
транзакции. Бинарный upload транспорт проверяет сессию до чтения тела, JSON-
метаданные в ограниченном base64url-заголовке X-Record, максимум две операции.
Таймаут получения запроса 120 секунд, простой соединения остаётся 10 секунд.

Область: fileRecords.ts, uploadTransport.ts, runtime.ts, app.ts, тесты.
Проверки: байты/владение, квоты, неверный заголовок, ранний 401, 413,
конкурентный лимит и освобождение слота; npm run check, diff --check.
Коммит: feat(api): T171b1 защитить передачу файлов
