# T049 — локальный репозиторий проверенных документов

Зависимость: T048.

Наблюдаемый результат: локальный репозиторий проверенных документов.

## Критерии

- Карточка документа: UUID, дата не в будущем, название ≤160, категория (анализ/выписка/исследование/другое), заметка ≤500 и уникальный fileId.
- PDF/JPEG/PNG/WebP ≤20 MiB проверяются по байтам; оригинальные байты сохраняются. Изображения дополнительно проходят header/размеры ≤64 млн пикселей/32768 px и настоящий декодер с освобождением bitmap; PDF не исполняется/не встраивается.
- Подготовка до RW; карточка и файл сохраняются атомарно с общей квотой 100 MiB. Поздний отказ откатывает обе записи.
- DB11 сохраняет прежние таблицы, добавляет documents; список валидируется и сортируется по дате/ID. Unit/browser подтверждают reopen, байты и ошибки.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/document.ts`, `src/media/prepareDocument.ts`, `src/data/documentRepository.ts`, `src/data/db.ts`.
