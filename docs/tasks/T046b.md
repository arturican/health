# T046b — Загрузка и галерея фото

Зависимость: T046a. Часть разрешённого полного локального MVP.

## Критерии

- Пользователь выбирает JPEG/PNG/WebP, дату, подпись и заметку; подготовленное фото сохраняется вместе с метаданными.
- Галерея упорядочена по датам, показывает изображения и подписи, включая пустое состояние; повторное открытие сохраняет записи.
- Ошибки связаны с полями, ввод сохраняется при отказе; подготовка JPEG, прозрачность и ограничения явно пояснены.
- Browser проверяет реальные upload/клики, клавиатуру, ширину 375 px, axe и отсутствие внешних запросов.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/pages/PhotoForm.tsx`, `src/pages/PhotoGallery.tsx`, `src/pages/PhotosPage.tsx`, `src/App.tsx`.
