# T171d — API показателей и истории

Зависимость: T171c. CRUD ручных показателей с сохранением числа/текста,
оператора, единицы и источника. Пагинированная история возвращает документ
в том же снимке чтения. Источник нельзя менять. Правка показателя меняет
revision документа, чтобы прежнее подтверждение удаления стало недействительным.

Область: labRecords.ts, labRoutes.ts, runtime.ts и HTTP/SQL тесты.
Проверки: число/текст/границы, пустая история, пагинация, неизменяемый источник,
чужой доступ, конкурирующая правка, rollback; npm run check и diff --check.
