# T218 — Отклонение недопустимого текста до PostgreSQL

Зависимость: T217. Статус — в TASKS.md.

P2. POST продукта с U+0000 подтверждённо даёт internal_error 500: Zod принимает
строку, PostgreSQL text её отклоняет. Та же граница есть у метаданных/копий.

Результат и критерии:
Общая граница серверного ввода возвращает invalid_data 400 до записи
для NUL в тексте JSON, метаданных и импорта. Нет частичных изменений и роста
ревизии; обычный Unicode и переводы строк допустимы. Форматы данных сохраняются.

src/server/httpErrors.ts и подходящие regression-тесты API/импорта/метаданных.
Не менять медицинские пороги, SQL-схему или зависимости.
Проверки: воспроизводящие и целевые серверные тесты, lint/types/build:api,
docs/diff; полный check перед push.
Отдельный коммит, затем следующий согласованный этап.
