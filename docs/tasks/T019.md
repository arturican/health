# T019 — Модели питания и расчёт порций в граммах

Зависимость: T018a.

Наблюдаемый результат: Модели питания и расчёт порций в граммах.

## Критерии

- Калории/БЖУ на 100 г и формула порции определены до реализации.
- Снимок записи независим от продукта; неизвестные БЖУ null, нулевые — 0.
- Strict-валидация проверяет ID, даты, поля, технические пределы и конечные числа.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/nutrition.ts`, `src/domain/nutrition.test.ts`, `docs/CALCULATIONS.md`.
