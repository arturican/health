# T037 — Неизменяемые версии энергетического плана со снимком параметров

Зависимость: T036.

Наблюдаемый результат: Неизменяемые версии энергетического плана со снимком параметров.

## Критерии

- Версия содержит UUID, уникальный последовательный revision, createdOn/effectiveFrom и снимок кг/даты веса/роста/возраста/параметра формулы.
- Цель null/0–100 000 отделена от способа расхода: none, общий manual 0–100 000, или factor >0–10. Пределы технические, не рекомендации.
- Новый план действует с сегодняшнего/будущего дня, прежние записи не обновляются. Действующая версия выбирается по дате, затем revision.
- Изменение профиля/веса не меняет старые снимки; одинаковая дата допускает новую версию, одновременная запись не теряет версии.
- Миграция сохраняет прежние таблицы, ошибки чтения/записи проверяются. Шаги/тренировки не добавляются к общей оценке.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/energyPlan.ts`, `src/data/db.ts`, `src/data/energyPlanRepository.ts`.
