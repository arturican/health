# T175e4 — Активность через общий источник

Зависимость: T175e3. StepsForm, WorkoutForm, WorkoutJournal, ActivitySummary,
ActivityOverview используют фасад. Шаги фиксируют исходную запись при первом
вводе/отправке и при открытии удаления; фон не подменяет версию. После ошибки
можно явно загрузить сохранённый итог, отбросив черновик. Тренировки передают DTO.
Сводки используют согласованные чтения без изменений расчётов/графика.

Проверки: регрессии фона/черновика/исходной версии и удаления, существующие
сценарии активности; полный npm run check, diff --check.
Коммит: refactor(ui): T175e4 сохранить исходные версии активности
