# T163a — хранилище сессий

Зависимость: T162. Разделение T163 до реализации: сначала SQL/сроки,
затем T163b HTTP/CSRF/rate limit. Результат — сессия принадлежит аккаунту,
проверяет пароль, хранит только SHA-256 случайного 256-bit токена.

Абсолютный срок 7 суток, неактивность 24 часа; точная граница исключается.
Повторный вход меняет токен и отзывает предъявленный прежний. Logout повторяем.
Время явно передаётся из серверных часов, тесты используют фиксированные даты.
Unknown login выполняет Argon2id-проверку dummy hash без раскрытия существования.

Область: src/server/sessions.ts, тесты и краткая документация.
Проверки: настоящий PostgreSQL/runtime, верный/неверный пароль, rotation,
отзыв/истечение/границы, отсутствие plaintext токена в БД, полный check.
