# T172d5 — Вместимость метаданных после импорта

Зависимость: T172d4. Изменение видимости после импорта не должно превышать
лимит метаданных полной копии. При заполненной квоте новая настройка отклоняется
без изменения данных; существующая настройка остаётся редактируемой.

Область: diaryState.ts и регрессионный HTTP/SQL тест полного импорта.
Проверки: воспроизведение ошибки, предельная квота, экспорт после отказа,
повторное редактирование; npm run check, git diff --check.
Коммит: fix(api): T172d5 сохранять экспорт при полной квоте метаданных
