# T028 — Экспорт текстовой резервной копии без файлов

Зависимость: T027.

Наблюдаемый результат: Экспорт текстовой резервной копии без файлов.

## Критерии

- Экспорт читает все таблицы области одной readonly-транзакцией, включая архив и снимки.
- Формат/версия/схемы явны; повреждённые записи и слишком большой текст отклоняются.
- JSON скачивается локально; object URL освобождается и ссылка удаляется.
- Название файла содержит дату экспорта, без личных параметров; файлы не включены.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/backup.ts`, `src/data/backupRepository.ts`, `src/ui/download.ts`, `src/pages/SettingsPage.tsx`, `src/App.tsx`, `src/data/backupRepository.test.ts`, `src/ui/download.test.ts`, `src/pages/SettingsPage.browser.test.tsx`.
