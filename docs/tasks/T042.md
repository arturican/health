# T042 — доступный график истории веса по календарным датам

Зависимость: T041.

Наблюдаемый результат: доступный график истории веса по календарным датам.

## Критерии

- Чистая функция проверяет записи и уникальность дат, сортирует по календарю; интервалы X соответствуют дням без DST, Y — весу.
- Пустая/одиночная/постоянная история не дают NaN или деления на ноль; исходные записи не изменяются.
- SVG имеет доступное имя/описание и адаптируется к ширине; реальные числа доступны в существующей истории измерений.
- Диапазон шкалы явно подписан; отсутствуют диагнозы, медицинские пороги и оценочные цвета.
- Browser подтверждает изменение/удаление весов и графика, клавиатуру, axe375 и отсутствие внешних запросов.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/weightPlot.ts`, `src/ui/WeightChart.tsx`, `src/pages/WeightPage.tsx`, `src/styles.css`.
