# T017 — Сквозная проверка профиля и веса на production-сборке

Зависимость: T016.

Наблюдаемый результат: Сквозная проверка профиля и веса на production-сборке.

## Критерии

- Production-сборка: создание профиля, добавление/повторная дата/перенос/отмена/удаление веса.
- Перезагрузка сохраняет записи; редактирование роста не создаёт измерение.
- Клавиатурный skip link сохраняет маршрут, ошибки ввода не записывают данные.
- Один сценарий проходит в desktop и mobile проектах без ошибок и внешних запросов.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `tests/e2e/profile-weight.spec.ts`, `docs/TEST_CASES.md`.
