# T178b — Восстановление и итоговая документация

Зависимость: T178a. Выполнить настоящее восстановление зашифрованной копии health,
скачанной с offsite VPS: сверить SHA, проверить GPG, поток без plaintext-файла в
новую health_restore_<random>. Перед созданием убедиться, что имя свободно;
не использовать --clean/-C. Сверить записи/файлы/ограничения/RLS и доступ ролей.
После проверки удалить только созданную временную БД. Исходный кластер не трогать.

Обновить README, .env.example, storage/privacy/deployment/backup документацию
и короткий отчёт: сущности/demo/screens/VPS/checks/ограничения, локальные коммиты.
Дополнительно проверены чужие запросы на HTTPS временным аккаунтом (удалён),
настроено role-level SQL logging без изменения чужих ролей; реальные новые
соединения и HTTPS после рестарта подтверждают настройки.
Проверки: фактический restore drill, рабочие сервисы/health/401, check:docs,
diff --check. Последняя полная проверка приложения — T178a, код не меняется.
