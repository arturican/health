# T001 — минимальный проект с тестовой основой

Зависимость: T000. Результат: запускаемый русский стартовый экран и проверки,
которые можно выполнить на чистой установке.

## Объём

React + TypeScript + Vite, обычный CSS, зафиксированный Node LTS и точные зависимости.
Vitest + Testing Library для компонентов, Playwright для первого браузерного smoke,
общая команда `check`. Тестовая основа добавлена сюда по явному запросу пользователя.

Основные файлы: `package.json`, lock-файл, `.nvmrc`, `.gitignore`, `index.html`,
`src/main.tsx`, `src/App.tsx`, `src/styles.css`, TypeScript/Vite/Vitest/Playwright
конфигурация и файлы тестов. Конфигурация и тесты учитываются отдельно от бюджета
ручной реализации приложения: не более пяти файлов и 250 строк.

## Критерии

- `npm ci` устанавливает зависимости без конфликтов engines/peerDependencies.
- `npm run dev` и production-preview показывают «Дневник здоровья».
- Интерфейс по-русски, доступен с клавиатуры и на узком экране; ссылки работают.
- TypeScript strict проверяет приложение, конфигурацию и тесты.
- Тесты проверяют наблюдаемое поведение и production-загрузку без ошибок.
- `npm run check` и `git diff --check` проходят.
- Версии и официальные источники совместимости записаны в документации.
- README содержит рабочие команды; TASKS и PROGRESS обновлены.

Профиль, данные, расчёты, навигация между разделами, IndexedDB и интеграции
остаются в будущих задачах. Рекомендуемый коммит:
`feat(app): T001 bootstrap diary with test foundation`.
