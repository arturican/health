# T262 — SMTP второго VPS

После T252a, явный выбор пользователя. Наблюдаемый результат: самостоятельный
исходящий MTA на159.194.208.200, прежний recipient, проверенный host-profile
и готовые точные DNS/PTR записи. До DNS/receipt отправка отложена.

Файлы реализации: deploy/check_mail.py и два небольших monitor overrides
Postfix/OpenDKIM (≤5/250). Тесты test_check_mail.py, документы MAIL_MONITOR/
MAIL_DNS/BACKUP_CONTROL отдельно. Не менять приложение/data SMTP keys,
системный hostname, SSH/agent connections, существующие DNS сайта или backups.

Порядок:
1. Регрессии host-specific gate: сохранить default data; frontend profile
   не требует локальной рабочей БД/API; shared auth SPF конфигурируется явно.
   Проверять точный одиночный SPF, оба PTR/A, selector/key и прежние security gates.
2. Native package simulation/точные версии Ubuntu24.04. Только новые нужные
   Postfix/OpenDKIM/tools без общего upgrade. Исключить autostart до loopback/
   privacy/defer config, сохранить rollback и исходные службы.
3. Отдельная RSA2048 DKIM пара на frontend, private0600/opendkim. Только public
   TXT публикуется в docs. Перенести recipient безопасно, не через AI/output.
4. Native Postfix/OpenDKIM syntax, loopback25/8891, mandatory verified TLS,
   sender restriction/tempfail/privacy; deferred .invalid fixture, реальная
   RSA/body проверка DKIM, удалить только собственный queue id.
5. Проверить DNS/PTR через доступный resolver и совпадение ключа.
   При отсутствии управления DNS подготовить точные записи и запросить действие
   оператора; сделать всё доступное без включения непроверенной доставки.
6. После DNS — пустая очередь/включение, согласованное synthetic сообщение
   прежнему recipient, запросить receipt. Подтверждение SMTP отдельно от inbox.
7. Tests/docs/diff/staged review, commit/push по разрешённой очереди; frontend/API
   остаются доступны, рабочая БД не используется тестами.

Rollback: остановить только новые monitors/MTA, сохранить queue/state и вернуть
точные сохранённые конфиги/drop-ins; не удалять общую очередь/архивы и не
менять data SMTP. Общий AUD-011 не закрывается без T253a/T254c/receipt.
