# T172d1 — Версия изменений дневника

Зависимость: T172c3. changeRevision в GET /diary-state меняется атомарно с каждой
новой командой; не меняется при ошибке или повторе Idempotency-Key.
X-Diary-Revision, если задан, требует совпадения перед изменением. Импорт и
удаление будут требовать его для защиты подтверждённого снимка от новых записей.

Область: миграция 010, diaryState.ts, writeCommand.ts и HTTP/SQL тесты.
Проверки: повтор, rollback, другой аккаунт, старое подтверждение и конкурентные
команды; npm run check, diff --check.
