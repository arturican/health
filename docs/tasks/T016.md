# T016 — Справочная карточка ИМТ без диагностики

Зависимость: T015.

Наблюдаемый результат: Справочная карточка ИМТ без диагностики.

## Критерии

- Карточка использует последний подходящий вес и явно показывает его дату.
- Нет нужных данных — объяснение вместо нуля; до 20 лет нет взрослой категории.
- Число округляется только для отображения; категория, источник и ограничения видимы.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/BmiCard.tsx`, `src/ui/BmiCard.test.tsx`, `src/pages/WeightPage.tsx`, `src/pages/WeightPage.browser.test.tsx`, `src/styles.css`.
