# T274 — Учение восстановления на синтетических данных

Зависимость [T273](T273.md). Результат — воспроизводимая проверка резервной
копии на текущем коде в выделенной локальной PostgreSQL. Историческое учение
T207 остаётся доказательством предыдущего прогона.

1. Сверить локальный Node, Docker, образ PostgreSQL 18.3, GnuPG и отдельный
   `TEST_DATABASE_URL` с регламентом. Рабочая среда сайта в прогоне не участвует.
2. Выполнить `npm test -- src/server/backupRestore.test.ts`. Существующий тест
   создаёт данные и временный ключ, шифрует dump и восстанавливает в новую БД.
3. Зафиксировать SHA, версии инструментов, длительность и результат проверки
   таблиц, исходных байтов вложений, миграций, прав и отзыва сессий и ссылок.
   Отдельно подтвердить отказ повреждённой копии и очистку временных ресурсов.

Готово, когда все проверки пройдены и результат добавлен в PROGRESS. При сбое
зафиксировать отличие окружения или открыть карточку исправления с регрессией.
Обновить TASKS/PROGRESS, `check:docs`, `git diff --check`, один локальный коммит.
