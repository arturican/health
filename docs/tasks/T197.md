# T197 — Сократить повторное изучение проекта в Codex

Запрос пользователя: отдельная задача настройки процесса без изменения продукта,
архитектуры, зависимостей, глобальных настроек и подключений. Основа — состояние
после T196; незавершённые задачи других очередей не запускаются.

Результат: короткий AGENTS, одна карта актуального кода/команд, согласованные
WORKFLOW и шаблон старта с выборочным чтением по задаче.

Критерии:

- Обойти основные UI/API/данные/тесты/CI/deploy, проверить Git и конфигурацию Codex.
- Сохранить правила объёма, идей, Git, качества, приватности и медицинские границы.
- Убрать обязательное полное чтение README/PROGRESS и повторные действия без причины.
- Не ослаблять обязательные проверки приложения/CI; документация проверяется отдельно.
- Проверить локальные ссылки, реальные пути/команды и согласованность инструкций.
- Записать подтверждённые причины лишнего чтения и ограничения проверки настроек;
  рекомендации по инструментам не меняют подключения.

Файлы: AGENTS, START_ONE_TASK, README (ссылка на карту), TASKS/PROGRESS,
WORKFLOW, PROJECT_MAP, CODING_STANDARDS (вместо устаревшей структуры — ссылка
на карту) и эта карточка. Без кода приложения и новых тестов.
Проверки: npm run check:docs, git diff --check, ручная сверка карты с кодом,
package.json и CI, проверка staged diff перед локальным коммитом.
