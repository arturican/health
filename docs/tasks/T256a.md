# T256a — Pinned Mermaid syntax gate

Выбор T256: новая dev dependency mermaid ровно 12.2.0, lockfile с точным деревом,
без обновления существующих прямых зависимостей. Node >=22.12.0 совместим с
проектным Node24.22.0. DOM при необходимости — существующий jsdom30.1.2.
Никаких remote render API, CDN, шрифтов или puppeteer download.

Добавить offline gate для всех mermaid fenced blocks собственного Markdown,
через общий список файлов check-docs. Valid/invalid flowchart/ER/sequence
synthetic fixtures; missing parser должен ломать gate. Проверить реальные
схемы, не игнорировать parse failures. Gate включён в npm check:docs/CI.
Не более 5 файлов реализации, 250 строк; tests/docs/lock отдельно.
npm audit точного нового дерева, lint/check:docs и build (Mermaid не входит
в приложение). Parser подтверждает синтаксис, не соответствие коду/читаемость.
Если browser rendering доступен, отдельно локально отрендерить реальные схемы
и осмотреть без внешней сети; иначе явно оставить ограничение.
