# T165a — общие схемы в Node-сборке

Зависимость: T164. T165 разделён до реализации: сборка/валидация,
API профиля, API веса. Общие domain-схемы имеют bundler-style импорты;
NodeNext не может их выпускать без переработки всех файлов.

Используется уже установленный Vite SSR build для Node, отдельно от dist.
TypeScript по-прежнему проверяется строго и отдельно от сборки; новые
зависимости не добавляются. Реквизиты БД не подставляются в JS.

Область: vite.server.config.ts, tsconfig.server.json, package.json,
src/server/recordValidation.ts. Профиль/вес переиспользуют Zod domain;
будущие даты определяются явным днём в IANA timezone аккаунта.

Проверки: собранные entrypoints и HTTP/shutdown, общие ограничения/даты,
отсутствие synthetic secret в JS, полный check; git diff --check.
