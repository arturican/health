# T238 — Диагностика исчерпания журнала команд

Зависимость: T237. IMP-007 / AUD-006. Статус — в TASKS.md.
Результат: предел100000 команд даёт409 command_capacity и безопасное понятное
сообщение. В ответе X-Health-Error-Code=command_capacity; клиент принимает
только эту комбинацию409/allowlisted code, не читает произвольные error bodies.
Данные/revisions не меняются; чтение, копии и replay прежнего key доступны.
Не предлагать удаление дневника. Очистку/ротацию определяет следующая T239.

Файлы реализации: server/commands,httpErrors,app и client/http (4/250).
Тест: настоящие HTTP/PostgreSQL,99999→100000→отказ/replay, owner isolation,
revision rollback и text/full export. Клиент: безопасный allowlist header,
неверные code/status не меняют общее сообщение, error body не отображается.
Проверки: FAIL до изменения; связанные writeCommand/commands/http unit,
types/build:api/lint/docs/diff/staged review. Общий check перед push очереди.
