# T061b — восстановление клавиатурного фокуса в журналах веса и еды

Зависимость: T061a.

Наблюдаемый результат: восстановление клавиатурного фокуса в журналах веса и еды.

## Критерии

- Вес: начало правки фокусирует дату; сохранение/отмена правки/удаление возвращают фокус к вводу веса. Ошибка подтверждённого удаления оставляет диалог и фокусирует отмену.
- Еда: сохранение новой записи, отмена/завершение правки и удаление возвращают фокус к выбору продукта; при отсутствии активных продуктов — к заголовку формы. Черновик нового ввода не теряется из-за удаления другой строки.
- Кнопка отмены удаления возвращает исходный opener; pending не запускает второе действие, ошибка сохраняет данные для исправления/повтора.
- Chromium сначала воспроизводит потерю фокуса на прежнем коде, затем проверяет реальные клики/клавиатуру; RTL проверяет обычные и ошибочные переходы.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/WeightPage.tsx`, `src/pages/FoodJournal.tsx`, `src/pages/FoodForm.tsx`.
