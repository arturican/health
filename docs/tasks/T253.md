# T253 — Независимый probe доступности

Связь: IMP-022, после T252. Наблюдаемый результат — ограниченная проверка
доступности API со второго VPS через существующий туннель.

Изменения: deploy/watchdog_probe.py и тесты. Только GET health/readiness на
127.0.0.1:53101, без авторизации, переходов по redirect и записи данных.
Принимается точный JSON до 1 KiB; timeout сокета 5 секунд, общий deadline CLI
15 секунд. Вывод содержит только фиксированные технические статусы.

Проверки: синтетический HTTP-сервер, ошибки соединения и deadline; запуск
по stdin на frontend VPS без установки, состояния и email; check:docs и diff.

State, доставка и timer выделены до реализации в T253b. Активация T253a
зависит также от выбора независимого канала T252a. Probe сам по себе
не обеспечивает доставку оповещений.
