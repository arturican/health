# T175e8 — Сохранение планов и видимости

Зависимость: T175e7. EnergyPlanForm/Settings и PrivacySettings используют фасад.
Исходный DTO фиксируется первым вводом или отправкой и сохраняется при ошибке.
План получает последнюю числовую ревизию независимо от даты действия.
Видимость не сохраняется после неудачного чтения: доступен явный повтор.
Фоновое обновление не сбрасывает черновик.

Проверки: исходная версия при фоновом изменении/повторе, блокировка до чтения;
существующие настройки, полный npm run check, git diff --check.
