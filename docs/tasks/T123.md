# T123 — локализовать ошибку расчёта ИМТ

Основание: согласованные аудиты, QA-04 / AUD-05. Зависимость: T122.

- При непредставимом результате карточка сообщает о невозможности расчёта
  и предлагает проверить рост и измерение, без выдуманного значения/категории.
- Сводка, история и форма веса доступны; route StorageBoundary не срабатывает.
- Отсутствие параметров остаётся отдельным состоянием. Формула, схема,
  клинические пороги, единицы и хранимые данные не меняются.
- Проверяются допустимые схемой крайние параметры с переполнением и underflow;
  браузерный сценарий исправляет рост через профиль и восстанавливает карточку.

Область: BmiCard, BmiCard.test, App.test, WeightPage.browser.test,
TEST_CASES, карточка/статусы. Проверки: RED, targeted unit/Browser GREEN,
axe/фокус/сохранность записей, полный `npm run check`, `git diff --check`.

Коммит: `fix(bmi): T123 локализовать ошибку расчёта в карточке`.
