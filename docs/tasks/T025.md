# T025 — Правка и подтверждённое удаление записей еды

Зависимость: T024.

Наблюдаемый результат: Правка и подтверждённое удаление записей еды.

## Критерии

- Правка массы/приёма/даты/комментария сохраняет ID и старый снимок продукта.
- Архивирование продукта не запрещает правку старой записи еды.
- Отмена правки и удаления ничего не меняет; удаление требует подтверждения.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/foodRepository.ts`, `src/pages/FoodForm.tsx`, `src/pages/FoodJournal.tsx`, `src/pages/NutritionPage.tsx`, `src/data/foodRepository.test.ts`, `src/pages/FoodJournal.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`.
