# T219 — Удаление прежних реализаций авторизации

Зависимость: T218. Статус — в TASKS.md.

P3. server/loginLimit.ts и registration.ts используются только старыми тестами;
runtime уже применяет PostgreSQL authRateLimit и email-first регистрацию.

Результат и критерии:
Удалить неподключённые Map-лимитеры/production wrapper. Полезные проверки
неизменяемой SQL register_account сохранить непосредственно в тесте;
proxy-проверка использует действующую реализацию. Сохраняются закрытый прежний
HTTP-маршрут, email-путь, domain/registration и все SQL-миграции.

Не более 5 файлов приложения; auth/proxy/registration regression-тесты,
lint/types/build:api и docs/diff; полный check перед push.
Не удалять legacy data adapters: они используются тестами и явным экспортом.
Отдельный коммит, затем следующий согласованный этап.
