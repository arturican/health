# T175e1 — Общий интерфейс и сводка «Сегодня»

Зависимость: T175d. Фасад dataAccess задаёт новые сигнатуры операций для UI.
Временный локальный адаптер позволяет переносить экраны отдельными коммитами
без смешивания двух источников в работающем приложении. При общем переключении
он остаётся только для существующих изолированных UI-тестов.

Пять файлов: dataAccess, legacy/dataAccess, legacy/summaries, client/summaries,
TodayPage. Сводки сохраняют локальные транзакции и используют consistentRead
в API-варианте. Расчёты/дизайн не меняются. Проверки: реальные API-сводки,
существующие TodayPage/браузерные сценарии, полный npm run check, diff --check.
Коммит: refactor(ui): T175e1 выделить источник данных и сводки
