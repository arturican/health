# T175a — API профиля, веса и продуктов

Зависимость: T174d. Четыре клиентских модуля: mutations, profileRepository,
weightRepository, productRepository. Чтение валидируется, списки полностью
пагинируются; правка/удаление передают revision исходного DTO. Создание использует
стабильный UUID команды, игнорируя новый UUID, создаваемый формой при повторе.
Поведение upsert веса, сортировка каталога и архив сохраняются.

Проверки: клиент → Fastify → отдельная PostgreSQL без настоящей сети;
создание/чтение/правка/удаление, устаревшая версия, повтор после потери ответа,
архив/seed, пустота и некорректный ввод. npm run check и diff --check.
