# T172b4 — Защита вложений и показателей

Зависимость: T172b3. Фото, документы и показатели используют generation
и Idempotency-Key. Дескриптор загрузки включает метаданные и SHA256 байтов.
Запоздавшая загрузка не восстанавливает дневник после смены generation.

Область: photoRoutes.ts, documentRoutes.ts, labRoutes.ts; интеграционные тесты.
Проверки: отложенная загрузка, повтор/конфликт файла, старые команды каждого
маршрута, повтор показателя и удаления; npm run check, diff --check.
Коммит: feat(api): T172b4 защитить команды вложений
