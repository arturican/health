# T139 — Desktop-макет фото

Зависимость: T138. Этап включён в запрос семи Desktop-разделов.

## Результат

Галерея и сравнение фото, лист форм/состояний. Файлы photos.cjs, SVG/PNG/JSON,
галерея и документы задачи. Только геометрические демо-изображения.

## Критерии

- Добавление: дата, подпись, заметка, файл JPEG/PNG/WebP; ограничения текущего UI.
- Правка метаданных без замены файла; удаление карточки вместе с файлом.
- Сравнение разных фото с датами и сохранением пропорций, без медицинской оценки.
- Меньше двух фото, одинаковый выбор, недоступное изображение, ошибка файла,
  загрузка, сохранение, пустая галерея и скрытый раздел.
- Сверка PhotoForm, PhotoGallery, PhotoComparison и FileImage.
- Просмотр PNG, проверка текста/геометрии/шрифта/контраста, check:docs и diff-check.
- Никаких реальных людей, облачных загрузок и изменений приложения.
