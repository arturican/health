# T004 — автоматические проверки доступности компонентов

Зависимость: T003a. Результат: компонентные тесты обнаруживают основные нарушения
семантики и доступных имён на существующем экране.

## Критерии

- Выбран совместимый инструмент проверки доступности и закреплена его версия.
- Стартовый экран проходит проверку без отключения применимых правил.
- В тестовом примере отсутствие доступного имени обнаруживается проверкой.
- TESTING объясняет ограничения автоматической проверки и обязательный keyboard smoke.
- Полный check проходит; новых продуктовых функций нет.

Коммит: `test(a11y): T004 check component accessibility`.
