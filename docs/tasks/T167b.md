# T167b — API записей еды

Зависимость: T167a. GET /food по дате с курсором UUID и лимитом 100.
POST создаёт снимок активного собственного продукта на сервере.
PUT меняет только дату, приём, массу, заметку; DELETE требует revision.
Старые снимки не меняются при правке/архивировании продукта.

Область: foodRecords.ts, foodRoutes.ts, runtime.ts и HTTP-тесты.
Проверки: CRUD/страницы, снимок, null/0, даты/числа, архив/чужой продукт,
владение, конфликт revision; npm run check, diff --check.
