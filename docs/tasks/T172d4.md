# T172d4 — Полное восстановление

Зависимость: T172d3. POST /backup/full использует тот же защищённый транспорт,
обязательные ключ/generation/changeRevision и режимы empty/replace; лимит 200 MiB.
После проверки всех файлов заменяет все области одним коммитом БД, сохраняя
неизвестные метаданные, но игнорируя прежнюю generation. Аккаунт/сессии остаются.

Область: restoreFull.ts, importRows.ts, backupRoutes.ts; HTTP/SQL тесты.
Проверки: полный round-trip/байты, повтор, одинаковые UUID двух владельцев,
пустые метаданные, повреждения, подтверждение/rollback; npm run check, diff --check.
