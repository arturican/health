# T183 — API регистрации

Зависимость: T182. Результат: POST /api/v1/auth/register создаёт новый аккаунт
без сессии; вход выполняется существующим защищённым маршрутом.

Область: общая схема регистрации, accounts.ts, registration.ts, auth.ts,
httpSecurity.ts; integration-тесты и документация.
Критерии: Origin обязателен; строгая схема; пароль 15–1024 символа;
201 только с публичным аккаунтом; 409 при занятом нормализованном логине;
400 при неверном вводе; максимум 10 попыток/15 минут на IP и четыре
одновременных хеширования вместе со входом. Forwarded IP не доверяется.
За текущим proxy IP общий; счётчик в памяти, рестарт сбрасывает его.
Нет почты, OAuth, восстановления пароля или изменения существующих сессий.
Проверки: API/PostgreSQL, полный npm run check, git diff --check.
Обнаруженный полным прогоном существующий тест DeleteDiary ожидает асинхронный
эффект фокуса через waitFor, сохраняя исходное утверждение доступности.
