# T194 — Восстановление, пароль по ссылке и привязка в UI

Зависимость T193. Результат: «Забыли пароль?» запрашивает reset-письмо,
ссылка #auth=verify_email/reset_password&token=... открывает форму нового пароля
и подтверждения. GET не погашает токен. Секрет очищается из history сразу,
не сохраняется в storage; после успеха очищается из памяти формы.
Пароль 15–1024, пробелы сохраняются; понятные ошибки/фокус/показ паролей.
После успеха нужен ручной вход, клиентские данные очищаются и другие вкладки
уведомляются. Ссылка обрабатывается также в уже открытом/вошедшем приложении.

Настройки показывают текущую почту и первичную привязку старого аккаунта:
почта/текущий пароль, письмо и новый пароль по ссылке. Смена уже привязанного
email не входит в запрос. Нет автоматического присвоения адресов старым аккаунтам.

Файлы: client/emailRecovery.ts, PasswordRecovery.tsx, EmailBinding.tsx,
AuthBoundary.tsx, pages/SettingsPage.tsx. До 250 строк реализации.
Проверки: пустой/неверный ввод/ошибки/сеть/повтор, пароль/совпадение/фокус,
валидные/неверные ссылки, отсутствие автопогашения/хранения/автологина,
статус/привязка только вошедшему; npm run check, build:api, diff check.
Финальные полные пользовательские E2E сценарии — T195, публикация — T196.
