# T005 — Безопасный разбор чисел и календарных дат

Зависимость: T004.

Наблюдаемый результат: Безопасный разбор чисел и календарных дат.

## Критерии

- Десятичная точка и запятая разрешены; разделители тысяч, exponent и мусор запрещены.
- Пустой необязательный ввод даёт null; ноль остаётся числом. Границы включительные.
- Даты Gregorian YYYY-MM-DD проверяются без UTC-сдвига календарного дня; год 0000 запрещён.
- Возраст вычисляется на выбранную дату, до/после дня рождения; будущая дата рождения отклоняется.

- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/input.ts`, `src/domain/input.test.ts`.
