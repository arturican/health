# T050a — просмотр и скачивание вложения документа

Зависимость: T049. Часть разрешённого полного локального MVP.

## Критерии

- DocumentFile повторно проверяет текущий fileId, показывает image через FileImage и разрешает скачать оригинальные байты только явной кнопкой.
- PDF не встраивается; скачивание использует локальный Blob URL и безопасное имя по UUID/подтверждённому MIME, ссылка удаляется и URL освобождается даже при ошибке.
- Чужой purpose, отсутствие файла и ошибка показывают общее сообщение без содержимого/имени файла; поздний ответ не показывает прежнее вложение.
- Unit и Chromium проверяют настоящие файлы, изображения, скачанные байты, отсутствие iframe/object/embed и освобождение URL.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/ui/download.ts`, `src/pages/DocumentFile.tsx`.
