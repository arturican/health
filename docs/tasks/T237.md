# T237 — Общий предел распаковки deploy tar

Зависимость: T236. IMP-006 / AUD-008. Статус — в TASKS.md.
Результат: до tarfile parser проверяется весь decompressed поток gzip, включая
PAX/GNU headers, padding и завершающие данные. Предел51MiB =50MiB содержимого
+1MiB служебного объёма; прежние20MiB compressed,1000entries/50MiB files остаются.
Архив выше предела отвергается до tar parse/изменения файлов. Обрезанный gzip
даёт штатный отказ без traceback. Новых зависимостей нет.
Реализация: install_release.py (до5/250). Тесты: PAX/GNU/repeated metadata
с масштабированным cap и spy до parser; current/assets неизменны; truncated,
правильные metadata, valid realdist/повтор/collision/previous.
Проверки: regression FAIL до изменения, все Python deploy tests, актуальный
build/verify_build, docs/diff/staged review. Установка receiver на сервер —
в разрешённом release после общих gates; локальный фикс сам live не меняет.
