# T058b — скрытие фото и документов через настройки интерфейса

Зависимость: T058a.

Наблюдаемый результат: скрытие фото и документов через настройки интерфейса.

## Критерии

- Настройки позволяют независимо показать/скрыть фото и документы с показателями; изменения применяются после сохранения и переживают remount.
- Скрытый раздел отсутствует в меню, его содержимое не читается/не отображается при прямом hash или истории браузера. Настройки всегда доступны.
- Загрузка или ошибка настроек консервативно скрывает содержимое обоих разделов; повреждение можно исправить явным сохранением валидных флагов. Сбой записи сохраняет прежнее состояние и позволяет повторить.
- Скрытие не удаляет записи и явно описано как настройка интерфейса, без обещаний защиты доступа/шифрования.
- Unit/Chromium проверяют реальные клики, прямые маршруты, историю, сохранность файлов, фокус, axe и мобильную ширину.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/useVisibility.ts`, `src/pages/PrivacySettings.tsx`, `src/pages/SettingsPage.tsx`, `src/ui/Navigation.tsx`, `src/App.tsx`.
