# T175g — Явная копия прежней браузерной базы

Зависимость: T175f. Три файла: native IndexedDB reader, компонент скачивания,
подключение в настройках. Только по кнопке, только readonly; отсутствующая база
не создаётся, старая схема не обновляется. Валидация существующих форматов/файлов.
JSON скачивается на устройство, не отправляется в API и не удаляет источник.
Импорт в аккаунт — отдельный существующий предпросмотр и согласие пользователя.

Проверки: отсутствующая/повреждённая база, readonly и неизменность, исходные байты,
кнопка/скачивание через настоящий браузер, полный npm run check, diff --check.
Коммит: feat(backup): T175g сохранить доступ к прежнему браузерному дневнику
