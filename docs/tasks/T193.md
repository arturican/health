# T193 — Регистрация email-first и вход в UI

Зависимость T192. Результат: регистрация запрашивает почту и часовой пояс,
показывает одинаковое подтверждение запроса без раскрытия существования адреса.
Пароль задаётся только по ссылке (экран в T194). Вход принимает почту либо
прежний логин; пароли не нормализуются. Прежний публичный /auth/register закрыт.

Файлы приложения: client/auth.ts, AuthBoundary.tsx, RegistrationForm.tsx,
server/auth.ts; до 250 изменённых строк. Проверки: доступные названия/ошибки/
фокус, валидация до сети, повтор/ошибка/ожидание, отсутствие автологина;
API закрытия старого маршрута; полный npm run check, build:api, diff check.
E2E сохраняют создание профиля/изоляцию и обновляются на email-first. Локальный
SMTP принимает синтетические письма; тестовый mailbox существует только
в tests/e2e/setup.ts. До T194 E2E погашает ссылку через API, затем проверяет вход.
Рабочий VPS не меняется, интерфейс публикуется только после завершения очереди.
