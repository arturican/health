# T181 — Исправить вёрстку входа

Зависимость: T180. Запрос пользователя: данные для входа и съезжающая вёрстка.
Один результат: компактная адаптивная карточка входа с разделёнными полями
и кнопкой, доступная также в низком окне и при сообщении об ошибке.

Область: src/client/AuthBoundary.tsx, src/client/auth.css,
tests/e2e/api-auth.spec.ts, TASKS.md, docs/PROGRESS.md и эта карточка.
Не менять авторизацию и не публиковать пароль демонстрационного аккаунта.

Критерии: карточка по центру, ширина до 480 px; поля и кнопка в одну колонку
с отступами; нет горизонтального переполнения на 320/375/768/1440 px;
при высоте 400 px доступны все поля, кнопка и ошибка через прокрутку.
Проверки: воспроизводящий Playwright regression, полный npm run check,
git diff --check. Только синтетический аккаунт локального E2E.
