# T051 — редактирование и подтверждённое удаление документов

Зависимость: T050b.

Наблюдаемый результат: редактирование и подтверждённое удаление документов.

## Критерии

- Метаданные документа редактируются без изменения fileId/оригинальных байтов; неверный ID/дата/категория и отсутствующая карточка отклоняются.
- Подтверждённое удаление документа без показателей удаляет карточку/файл одной транзакцией. Отмена сохраняет всё; поздний отказ откатывает обе записи.
- Правка сохраняется при ошибке; кнопки блокируются при сохранении/удалении, фокус возвращается в доступную форму/заголовок.
- Unit/Chromium проверяют редактор, отмену/подтверждение, байты, атомарность, remount, клавиатуру и 375 px/axe.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/documentRepository.ts`, `src/pages/DocumentForm.tsx`, `src/pages/DocumentList.tsx`, `src/pages/DocumentsPage.tsx`.
