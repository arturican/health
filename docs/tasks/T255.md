# T255 — Проверка anchors и полного собственного Markdown

IMP-024 / AUD-012. scripts/check-docs.mjs: обход собственного Markdown,
включая design; исключить зависимости, Git и generated build/test outputs.
Проверять локальный путь и fragment Markdown, URL decoding, кириллицу,
дубли заголовков, explicit HTML anchors; не интерпретировать fenced code
как настоящие ссылки/заголовки. Без сети и новых зависимостей.

GitHub rules: lowercase, пробелы в hyphen, удаление punctuation/formatting,
суффиксы повторов. Источник:
[GitHub section links](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#section-links).
Реализовать используемый проектом Markdown, не заявлять полный CommonMark parser.

Файлы реализации: script и npm check:docs; синтетические node:test fixtures.
Отрицательные случаи path/fragment/design должны ломать gate; положительные
кириллица/encoding/дубли/fences/HTML anchors проходят. Исправить обнаруженные
реальные ссылки отдельными docs правками. node tests, check:docs/lint/diff.
