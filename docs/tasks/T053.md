# T053 — ручной ввод и просмотр показателей бланка

Зависимость: T052.

Наблюдаемый результат: ручной ввод и просмотр показателей бланка.

## Критерии

- Пользователь явно выбирает документ-источник по дате/названию, вводит дату, название показателя, тип (число/текст), знак сравнения, результат, единицы, референс и заметку.
- Числовой ввод поддерживает точку/запятую и сохраняет 0/отрицательные без округления. Референс отображается как введён, без сравнения единиц/диагноза.
- Список относится только к выбранному документу, упорядочен по датам; пустые единицы/референс обозначены как не указанные.
- Смена источника сбрасывает форму; исчезнувший документ убирает старые показатели. При отказе ввод остаётся, повторный submit блокируется, фокус и поле ошибок доступны.
- Unit и Chromium проверяют все поля, типы/знаки, source-switch/remount, клавиатуру, 375 px/axe/no external HTTP.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/LabForm.tsx`, `src/pages/LabList.tsx`, `src/pages/LabSection.tsx`, `src/pages/DocumentsPage.tsx`, `src/domain/labResult.ts`.
