# T035 — Правка и подтверждённое удаление тренировок

Зависимость: T034.

Наблюдаемый результат: Правка и подтверждённое удаление тренировок.

## Критерии

- Правка сохраняет ID, позволяет изменить поля и дату, не затрагивает соседние записи или шаги.
- Несуществующая/повреждённая запись, неверные значения и будущая дата не изменяют базу; ошибка записи откатывается.
- Отмена правки/удаления сохраняет данные. Удаление идемпотентно на API и подтверждается в интерфейсе.
- Browser проверяет перенос между днями, remount, keyboard/focus, mobile/axe. После действий фокус остаётся на доступном элементе.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/workoutRepository.ts`, `src/pages/WorkoutForm.tsx`, `src/pages/WorkoutJournal.tsx`.
