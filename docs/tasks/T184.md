# T184 — Интерфейс регистрации

Зависимость: T183. Результат: кнопка «Зарегистрироваться» на входе открывает
работающую форму; успешное создание возвращает ко входу с логином и пустым паролем.

Файлы: AuthBoundary.tsx, RegistrationForm.tsx, auth.ts, auth.css и тесты.
Критерии: подписи и ошибки полей, подтверждение пароля, показ паролей,
часовой пояс браузера с возможностью исправления; pending блокирует повторы
и переходы; понятные ошибки занятого логина/сети; пароль не хранится постоянно.
Проверки: unit клиента и компонентов, полный npm run check, git diff --check.
Мобильная геометрия, axe и реальный API-сценарий дополнительно входят в T185.
