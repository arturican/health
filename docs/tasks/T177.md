# T177 — База, API и защищённое соединение на VPS

Зависимость: T176b. Пять файлов реализации: API service, tunnel service,
SSHD match snippet, Nginx config, срок graceful shutdown main.ts.
Существующий PG18 используется без изменения чужих БД/volumes; новая health,
отдельные migrator/runtime/app roles. Публичных DB/API портов нет.

До изменений есть зашифрованный baseline на двух VPS. Установка Node из
официального дистрибутива с проверкой SHA256; приватные env вне релизов.
Миграции с нуля и повтор, seed одного аккаунта и повтор без изменения данных.
Backend непривилегированный, systemd restart; frontend → localhost SSH tunnel
→ localhost API. Проверка SSH/Nginx до reload, старые конфиги сохраняются.
Включить и проверить ежедневную зашифрованную копию новой БД.

Проверки: npm run check, build:api, Python deploy, systemd/sshd/nginx validation,
HTTPS health/401, минимальные права, число строк после повторов/перезапуска,
отсутствие новых публичных портов, рабочие прежние сервисы, diff --check.
Frontend publication и фактическое восстановление копии — T178.
