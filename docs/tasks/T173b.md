# T173b — Повторяемая загрузка демонстрации

Зависимость: T173a. Административная CLI создаёт один аккаунт с Argon2id и
заполняет только его пустой дневник через ограниченную роль PostgreSQL.
Маркер demo-seed-v1 делает повтор безопасным: пароль и правки не меняются.
Данные, файлы и маркер записываются одной транзакцией; ошибка допускает повтор.

Область: seedRecords.ts, seedDemo.ts, auth.ts, package.json, vite.server.config.ts.
Проверки: реальные PostgreSQL/HTTP login, повтор/конкуренция, занятый дневник,
другая учётная запись, rollback, запрет admin runtime; npm run check, diff --check.
