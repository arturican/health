# T020 — Локальный справочник продуктов и безопасная миграция

Зависимость: T019.

Наблюдаемый результат: Локальный справочник продуктов и безопасная миграция.

## Критерии

- Миграция v2→v3 сохраняет старые данные и создаёт таблицу продуктов.
- Демо-продукты добавляются явно и однократно, не перезаписывают пользовательские записи.
- Чтение/запись валидируется; архив фильтруется без удаления.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/db.ts`, `src/data/productRepository.ts`, `src/data/productRepository.test.ts`.
