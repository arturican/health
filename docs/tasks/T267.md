# T267 — Документация для пользователя и сопровождения

Запрос от 25.11.2026: собрать полную документацию для владельца и для дальнейшей
работы Codex. Зависимость — [T266](T266.md). Исходный чистый срез `ffeb403`.

- [Оглавление](../README.md) ведёт к нужной инструкции по задаче и отличает
  рабочие справочники от истории. Оно доступно из README и карты проекта.
- [Руководство пользователя](../USER_MANUAL.md) покрывает аккаунт, восемь
  разделов, перенос и удаление дневника, копии и частые ошибки. Подписи и
  последствия сверяются с UI, API и тестами.
- [Руководство по сопровождению](../MAINTAINER_GUIDE.md) описывает запуск,
  передачу контекста, маршруты поиска, выбор проверок и первые действия при
  проблемах с выпуском. Существующие правила и регламенты остаются источниками
  точных требований. Архитектурная инструкция запуска сверяется с текущими npm scripts.

Изменения касаются документации. Проверки `npm run check:docs`, `git diff --check`,
локальный рендер новой схемы, просмотр staged diff и поиск сигнатур секретов.
Один локальный коммит.
