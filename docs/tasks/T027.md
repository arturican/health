# T027 — Атомарное копирование приёма пищи на другую дату

Зависимость: T026.

Наблюдаемый результат: Атомарное копирование приёма пищи на другую дату.

## Критерии

- Копируется один выбранный непустой приём в другую календарную дату.
- Источники/снимки/комментарии сохраняются, исходные и прочие записи не меняются.
- Ошибка bulkAdd откатывает все копии; исходный/целевой день полноты не меняется.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/foodRepository.ts`, `src/pages/CopyMealForm.tsx`, `src/pages/FoodJournal.tsx`, `src/data/foodRepository.test.ts`, `src/pages/CopyMealForm.test.tsx`, `src/pages/NutritionPage.browser.test.tsx`.
