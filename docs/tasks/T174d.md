# T174d — Повтор команд без дублирования

Зависимость: T174c2. В пределах текущего входа неопределённый результат сети
сохраняет исходную команду, UUID записи и отдельный idempotency key в памяти.
Одновременный повтор объединяется; успех и определённый отказ 4xx завершают
команду. Смена входа/generation очищает очередь; автоматической отправки нет.
Максимум 128 неопределённых команд, без вытеснения и скрытой потери ключей.

Область: client/commands.ts, тесты. Критерии: повтор той же команды/тела,
различные UUID, конкурентный вызов, неверный ответ, 4xx/5xx, сброс контекста,
отсутствие browser persistence и ограничение памяти. Полный npm run check.
