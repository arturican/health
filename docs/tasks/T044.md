# T044 — локальное хранение проверенных файлов

Зависимость: T043.

Наблюдаемый результат: локальное хранение проверенных файлов.

## Критерии

- Файл имеет UUID, назначение photo/document, канонический MIME, размер и Blob; метаданные совпадают с действительными свойствами Blob.
- prepareFile проверяет байты до транзакции, savePreparedFile сохраняет подготовленный объект и проверяет общий лимит 100 MiB атомарно.
- Внешние файлы идут через prepareFile, внешние резервные копии повторно проверяют байты до восстановления; savePreparedFile используется после подготовки.
- getFile валидирует ID, метаданные и структуру содержимого; неизвестный ID даёт null, повреждение/ошибка хранения не скрываются.
- Миграция v9 добавляет files, сохраняя прежние таблицы; Blob переживает закрытие/повторное открытие настоящей браузерной базы.
- Квота/дубли/ошибки откатывают запись; вложения остаются локальными без object URL или внешних запросов.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/storedFile.ts`, `src/data/fileRepository.ts`, `src/data/db.ts`, `docs/MVP.md`.
