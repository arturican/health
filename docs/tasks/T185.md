# T185 — Сквозная проверка регистрации и публикация

Зависимость: T184. Результат: браузер подтверждает регистрацию, вход и
изоляцию двух новых аккаунтов через настоящий API/PostgreSQL.

Файлы: tests/e2e/registration.spec.ts, tests/deployed/registration.spec.ts,
документация безопасности/публикации и статусы. Изменения реализации — только
при обнаруженной регрессии, с воспроизводящим тестом и в бюджете задачи.
Критерии: профиль/reload/logout/relogin, занятый логин не меняет пароль,
cookie/401, пустые постоянные хранилища, axe, клавиатура, 320/375/768/1440 px
и высота 400 px; просмотр снимков без паролей. Live smoke использует новые
синтетические аккаунты; сохраняет только точные логины для последующей очистки.

Проверки: полный npm run check, build:api, Python deploy tests, verify_build,
git diff --check. После коммита разрешены push/dev, CI/deploy, обновление API
с новой аддитивной миграцией и HTTPS smoke. Перед обновлением — свежая внешняя
зашифрованная копия. Backend доставляется перед frontend, старый вход совместим.

Коммит: test(auth): T185 проверить регистрацию и изоляцию в браузере
