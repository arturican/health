# T172c3 — Полный экспорт с вложениями

Зависимость: T172c2. GET /backup/full возвращает v1-копию всех областей в одном
снимке. Исходные файлы проверяются перед base64, включая размеры фото; скрытые
разделы включены. Лимит 200 MiB, общий слот операций копии. Generation исключена.
Миграция отличает отсутствующую настройку видимости от явно сохранённой.

Область: fullSnapshot.ts, backupRoutes.ts, diaryState.ts, миграция 009.
Проверки: PDF/JPEG байты, метаданные/null/текст/операторы, пустой и чужой аккаунт,
повреждённое содержимое и размеры; npm run check, diff --check.
