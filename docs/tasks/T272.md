# T272 — Общий серверный шаг записи вложения

Зависимость [T271](T271.md). Четвёртый шаг [T268](T268.md).
Обе операции создания вложения используют одну проверку байтов и одинаково
формируют отпечаток запроса для проверки повтора из метаданных и SHA256.
Маршруты сохраняют свои правила
чтения метаданных, назначение файла, лимиты, ответы и SQL-операции.

Файлы: `photoRoutes.ts`, `documentRoutes.ts`, `writeAttachmentCommand.ts`.
Проверки: API фото и документов, E2E вложений Desktop/Pixel 7, `build:api`,
typecheck, целевой ESLint и check:docs.
