# T060 — сквозные сценарии вложений, полной копии и отказов импорта

Зависимость: T059.

Наблюдаемый результат: сквозные сценарии вложений, полной копии и отказов импорта.

## Критерии

- Готовая сборка проверяется Playwright на Desktop Chrome/Pixel 7 только настоящими формами и кликами; Canvas создаёт лишь синтетические геометрические файлы, не данные базы.
- Фото: загрузка двух кадров, сравнение, правка метаданных, отмена/подтверждение удаления и reload. Документы: исходный PDF скачивается побайтно, поиск/правка; числовой и текстовый показатель, правка/удаление/каскад.
- Полная копия всех 13 таблиц скачивается на диск, заменяет удалённый дневник после предпросмотра/согласия и переживает reload. Повторный экспорт совпадает по IDs, записям и байтам, кроме даты экспорта.
- Неверный JSON/UTF-8/версия/связи/содержимое вложения не дают предпросмотра и не меняют текущий профиль; новый файл сбрасывает старое согласие.
- Каждый сценарий проверяет ошибки страницы/консоли, отсутствие внешних HTTP и горизонтального переполнения. Только синтетические файлы.
- Падение CI на b6d95ac проверяется по логам: unit-проверка фокуса предпросмотра ожидает завершения React-эффекта через waitFor, сохраняя исходное требование к фокусу без задержек и ослаблений.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `tests/e2e/media-photos.spec.ts`, `tests/e2e/media-documents.spec.ts`, `tests/e2e/full-restore.spec.ts`, `tests/e2e/invalid-full-backup.spec.ts`.
