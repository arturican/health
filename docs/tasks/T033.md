# T033 — Сохранение простых тренировок с ручной оценкой расхода

Зависимость: T032.

Наблюдаемый результат: Сохранение простых тренировок с ручной оценкой расхода.

## Критерии

- Строгая модель: UUID, дата, вид до 80 символов, длительность >0 до 1440 минут, ккал null или 0–100 000, источник и заметка.
- Будущие даты, неизвестные поля и нечисловые/бесконечные значения отклоняются; несколько тренировок в день разрешены.
- Чтение выбранного дня валидирует записи, сортирует устойчиво; миграция сохраняет прежние данные.
- Ккал вводятся вручную и не вычисляются из длительности или шагов; технические пределы не являются рекомендациями.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/activity.ts`, `src/data/db.ts`, `src/data/workoutRepository.ts`.
