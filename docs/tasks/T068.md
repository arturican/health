# T068 — автоматические проверки дизайна

Зависимость: T067.

- Небольшие визуальные эталоны локальных SVG-пиктограмм и области графика обнаруживают изменение формы, цвета, линии и выделения точки; шрифты и большие страницы не входят в pixel snapshots.
- Production-тесты проверяют размеры основных целей касания, квадратные пиктограммы внутри ссылок, видимый клавиатурный фокус и уменьшенное движение на разных экранах.
- Синтетические измерения создаются настоящими формами; время фиксировано, данные изолированы, нет ошибок страницы/консоли и внешних HTTP-запросов.
- Есть отдельные команды запуска набора и Playwright UI, инструкция просмотра screenshot diff и осознанного обновления эталонов.
- Полный `npm run check`, `git diff --check`, отдельный коммит `test(design): T068 добавить визуальные и браузерные проверки дизайна`, push dev и проверка CI точного HEAD.
