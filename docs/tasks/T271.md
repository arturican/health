# T271 — Скачивание проверенной полной копии без второй сериализации

Зависимость [T270](T270.md). Третий шаг [T268](T268.md).
Сравнить время двух путей подготовки полной копии в Chromium на одинаковом
синтетическом ответе. При выигрыше отдавать исходные байты после однократной
проверки. Сохранить проверку владельца и сессии, формат, лимит, обработку 413,
имя файла и совместимость с существующим восстановлением.

Файлы: клиентский репозиторий копий, `FullBackupExport`, тестовый legacy-адаптер.
Проверки: измерение Chromium, HTTP регрессии, browser export, E2E полного
восстановления, typecheck, связанный ESLint и check:docs.
