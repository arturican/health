# T050b — загрузка и поиск документов

Зависимость: T050a. Часть разрешённого полного локального MVP.

## Критерии

- Форма записывает дату, название, категорию, заметку и PDF/JPEG/PNG/WebP; объясняет локальное хранение, исходные байты и пределы.
- Список упорядочен по датам, поиск по названию/заметке/категории/дате не меняет данные; есть пустое состояние и отсутствие результатов.
- Ошибки связаны с полями, ввод/файл остаются при отказе, повторное сохранение блокируется; повторное открытие сохраняет документы.
- Browser проверяет upload/клики/скачивание, клавиатуру, 375 px/axe и отсутствие внешних запросов.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/pages/DocumentForm.tsx`, `src/pages/DocumentList.tsx`, `src/pages/DocumentsPage.tsx`, `src/App.tsx`.
