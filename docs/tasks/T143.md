# T143 — Пиктограммы и графики БЖУ в Desktop-макете питания

Зависимость: T142. Прямое уточнение пользователя к готовому макету питания.

## Результат и границы

Три карточки белков, жиров и углеводов с пиктограммами, граммами за день
и графиками по приёмам пищи. Только локальный макет, без изменения приложения,
адаптивности, новых зависимостей и подключения к реальным данным.
Файлы: design/desktop/nutrition.cjs, производные SVG/PNG/JSON и документы задачи.

## Критерии

- Все подписи, графики и дневной итог берутся из одного синтетического набора
  порций: 88 г белков, 64 г жиров, 188 г углеводов; 1680 ккал задаются отдельно.
- На графиках единая явно подписанная шкала граммов, без выдуманной нормы БЖУ.
- Источник для будущей реализации: выбранный день → listFood(day) → сохранённый
  snapshot продукта × grams / 100 → portion / foodTotals из src/domain/nutrition.ts.
  Смена даты, добавление, правка и удаление еды обновляют все представления вместе;
  изменение каталога не меняет прежние снимки. Подключение в этой задаче не делается.
- Неизвестный макронутриент означает неизвестный итог по нему; остальные независимы.
  Пустой неполный день — нет данных; подтверждённый пустой день — известный ноль.
  Эти состояния показаны на отдельном листе, отсутствие данных не рисуется нулём.
- PNG просмотрены; геометрия, контраст и локальная галерея проверены.
  Проверены суммы и пропорции полос; check:docs и git diff --check проходят.
- Обновлены пакет на рабочем столе, TASKS.md и PROGRESS.md; отдельный локальный коммит.
