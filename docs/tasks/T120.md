# T120 — сохранять черновик веса при удалении другой записи

Основание: согласованные аудиты, QA-01 / AUD-01. Зависимость: T076.

## Результат

- При удалении B открытый редактор A сохраняет введённые дату, вес и ошибки
  валидации; A не записывается автоматически. Фокус возвращается в поле веса.
- Удаление самой редактируемой записи закрывает её редактор.
- Отмена и ошибка удаления сохраняют черновик; ошибка видима, доступен повтор.
- Только синтетические данные; формат хранения и зависимости не меняются.

Область: WeightPage, unit и Native Browser regression, TEST_CASES, TASKS,
PROGRESS. Проверки: воспроизводящий RED, targeted GREEN, полный `npm run check`
и `git diff --check`.

Коммит: `fix(weight): T120 сохранять черновик при удалении другой записи`.
