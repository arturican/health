# T174c2 — Версии записей и согласованное чтение

Зависимость: T174c1. WeakMap связывает исходный DTO с revision и контекстом
входа/generation; новые чтения того же ID не подменяют версию открытого редактора.
Пагинация ограничена квотой, проверяет курсоры и загружает все страницы.
Сверка changeRevision до/после чтения исключает смешанный снимок; максимум три
попытки, затем явный конфликт. Новая generation сбрасывает контекст UI.

Область: client/records.ts, client/readState.ts, client/pages.ts, client/session.ts.
Проверки: старый DTO, вход/поколение, >100 записей, пустота/неверный ответ,
повтор/зацикленный курсор и конкурентное изменение; npm run check, diff --check.
Коммит: feat(client): T174c2 читать согласованные версии записей
