# T263a — Перенос общих секретов разработки

Запрос пользователя 21.10.2026: подготовить перенос между компьютерами,
проверить чистую копию и отправить отдельную ветку без production-деплоя.
Исходная рабочая копия чистая, dev 66de366, origin — существующий SSH GitHub.

Результат: SOPS + age, четыре новых случайных пароля только локальной разработки,
ключ вне Git, атомарное восстановление и явное обновление. Рабочего .env нет;
существующие demo/recovery/SSH credentials вне проекта относятся к VPS и
в development не переносятся. Production и существующий тестовый контейнер
не меняются. Новые CLI нужны именно для запрошенного шифрования; npm-зависимостей нет.

Файлы реализации: scripts/secrets.mjs, .gitignore, .sops.yaml,
secrets/development.enc.env (до 250 строк реализации, ciphertext отдельно как
сгенерированный артефакт). Тесты: scripts/secrets.test.mjs. TASKS/PROGRESS.
Очередь: T263a → T263b (локальные сервисы/команды) → T263c (инструкция/чистая копия).

Критерии: ключ переиспользуется, отсутствующий ключ даёт понятную ошибку;
restore не меняет существующий .env; refresh отказывает при локальных правках;
ошибка SOPS не портит файлы; encrypt замечает новую локальную/remote версию;
машинные настройки не входят в ciphertext; открытые секреты не печатаются.
Проверки: Node integration tests с настоящими SOPS/age и синтетическими
значениями, ESLint, check:docs, diff/staged/secret scan. Общие check/build:api —
после всей очереди перед push. SOPS 3.13.3 и age 1.3.2 получены из официальных
GitHub releases, SHA256 сверены с digest release API до установки в ~/.local/bin.

Официальные источники: [SOPS](https://github.com/getsops/sops/releases/tag/v3.13.3),
[age](https://github.com/FiloSottile/age/releases/tag/v1.3.2).
