# T009 — Модели профиля и измерений с runtime-валидацией

Зависимость: T008.

Наблюдаемый результат: Модели профиля и измерений с runtime-валидацией.

## Критерии

- Один профиль self, имя до 80 символов, положительный рост до 300 см, необязательная дата рождения не в будущем.
- Параметр формулы расхода none/male/female необязателен по смыслу; не выводится из имени или других данных.
- Измерение: UUID, календарная дата, положительный вес до 600 кг; верхние лимиты технические, не медицинские.
- Строки вместо чисел, NaN/Infinity, неизвестные поля и неверные даты отклоняются runtime-валидацией.
- Ошибки локализованы по-русски; миграция version 1 сохраняет metadata и добавляет профили/вес с уникальной датой.

- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/schema.ts`, `src/domain/profile.ts`, `src/data/db.ts`, `src/domain/profile.test.ts`, `package.json`, `package-lock.json`.
