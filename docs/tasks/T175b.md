# T175b — API питания и активности

Зависимость: T175a. Пять клиентских репозиториев: еда, полнота дня, шаги,
тренировки, энергетические планы. Пагинация/сортировка и исходные версии;
снимок продукта и снимок плана создаёт сервер. Копирование использует отдельные
UUID внутренней команды и транспортного повтора. Неизвестное остаётся null.

Проверки на настоящей PostgreSQL через Fastify: CRUD, копия и снимок,
полнота/шаги с нулём, версия плана и конфликт, чужой аккаунт и неверный ввод.
Полный npm run check; diff --check.
