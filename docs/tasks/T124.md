# T124 — закрепить шесть точных размеров экрана

Основание: согласованный QA-аудит, QA-05. Зависимость: T123.

- Дополнить существующий responsive-набор целевым сценарием для 375×812,
  390×844, 768×1024, 1280×800, 1440×900 и 1920×1080.
- На каждом размере реально открыть журнал с клавиатуры, ввести и сохранить
  измерение, отменить и подтвердить его удаление. Проверить фокус, доступность
  рабочего поля во viewport, видимое сообщение и сохранность исходной истории.
- После reload остаётся только исходная запись; нет переполнения, page/console
  errors и внешних запросов. Только синтетические данные, созданные через UI.
- Сохранить прежние пять ширин и короткий viewport. Не умножать весь E2E
  на шесть проектов, не менять UI или визуальные эталоны.

Область: существующий responsive.spec, TEST_CASES, карточка, TASKS/PROGRESS.
Проверки: targeted responsive E2E на обоих существующих проектах, полный
`npm run check`, `git diff --check`. Новая проверка расширяет покрытие,
не является регрессией уже обнаруженного дефекта; runtime не меняется.

Коммит: `test(responsive): T124 проверить действия на шести размерах экрана`.
