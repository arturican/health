# T175e9 — Копии и подтверждение удаления

Зависимость: T175e8. SettingsPage, FullBackupImport, FullBackupExport,
DeleteDiary используют фасад. Импорт фиксирует DiaryConfirmation до чтения файла,
удаление — до диалога. Повтор использует то же подтверждение; отмена/новый
предпросмотр требуют нового. Текст интерфейса не обещает браузерное хранение.

Проверки: порядок подготовки и чтения, исходное подтверждение при повторе,
ошибка подготовки без удаления, отмена/фокус; полный npm run check, diff --check.
