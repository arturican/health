# T040 — отдельные индикаторы цели и оценочного баланса

Зависимость: T039.

Наблюдаемый результат: отдельные индикаторы цели и оценочного баланса.

## Критерии

- Выбранный день показывает свой план, записанную еду и полноту; соседние даты и будущие планы не смешиваются.
- Цель, остаток и расход имеют отдельные подписи; суточный баланс доступен только при полном дне и известных величинах.
- При цели >0 доступный meter ограничен её диапазоном, действительная внесённая сумма и остаток остаются текстом с объявленным округлением; нулевая цель без meter.
- Способ расхода, источник/версия, округление и отсутствие дополнительного расхода активности объяснены. Нет оценочных цветов или медицинских рекомендаций.
- Browser проверяет реальные клики полноты/дат, клавиатуру, axe и ширину 375 px.
- После собственного сохранения полноты checkbox возвращает потерянный при pending фокус; начальная загрузка и смена дня не перехватывают фокус.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/EnergySummary.tsx`, `src/pages/NutritionPage.tsx`, `src/styles.css`, `src/ui/NutritionSummary.tsx`.
