# T041 — сводка выбранного дня вместо стартовой заглушки

Зависимость: T040a.

Наблюдаемый результат: сводка выбранного дня вместо стартовой заглушки.

## Критерии

- Главный экран содержит данные выбранного дня: последнюю доступную массу/ИМТ, питание/полноту, отдельные цель/баланс, шаги и журнал активности.
- Пустой профиль предлагает заполнение, отсутствующие значения остаются неизвестными; готовые функции переиспользованы.
- Общий выбор дня сохраняется между разделами; свежие данные помечены датой, предыдущий результат не показывается как новый.
- Удалена стартовая заглушка и её неиспользуемые стили; starter unit/browser/E2E проверяют реальное поведение.
- Проверены дневной сценарий, keyboard/mobile/axe, отсутствие внешних запросов и ошибок.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/TodayPage.tsx`, `src/ui/ActivitySummary.tsx`, удаление `src/ui/Welcome.tsx`, `src/App.tsx`, `src/styles.css`.
