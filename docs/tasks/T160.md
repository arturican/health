# T160 — PostgreSQL и миграции

Зависимость: T159. Результат — повторяемый инструмент SQL-миграций с checksum,
одной транзакцией и advisory lock. Ошибка откатывает весь набор; изменение,
удаление или перестановка уже применённой миграции отклоняется.

Область: package.json, src/server/database.ts, migrations.ts, migrate.ts,
migrations/001_foundation.sql; автоматически обновлённый lock-файл отдельно.
pg 8.23.1 / @types/pg 8.23.1 проверены через npm metadata и официальную
документацию node-postgres; Node >=16 совместим с закреплённым Node 24.22.0.

Тесты используют только TEST_DATABASE_URL в выделенной локальной БД health_test,
не имеют fallback на DATABASE_URL. Доступ к VPS для тестов не используется.
Проверки: fresh/repeat/checksum/concurrency/rollback в настоящем PostgreSQL,
ошибки конфигурации, типы/сборка API, полный npm run check, git diff --check.
