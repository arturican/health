# T174c1 — Реактивная загрузка без потери черновика

Зависимость: T174b2. Хук загрузки держит данные только в памяти компонента,
отбрасывает старые ответы при смене параметров/сессии. Фоновое обновление
сохраняет прежний результат и форму; ошибка видна с кнопкой повтора.
Начальная ошибка обрабатывается границей раздела с повторным открытием.

Область: client/queries.ts, client/useDiaryQuery.ts, client/QueryFeedback.tsx,
ui/StorageBoundary.tsx. Проверки: pending/empty/error/retry, смена дня/аккаунта,
черновик при обновлении, late response, focus/online, cleanup;
npm run check, git diff --check.
