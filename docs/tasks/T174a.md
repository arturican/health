# T174a — Клиентский транспорт и память сессии

Зависимость: T173c. Общий runtime-контракт аккаунта без серверных зависимостей,
сессия только в памяти, смена сессии отменяет запросы и запрещает старые ответы.
HTTP только /api/v1 того же origin, no-store, cookie/CSRF, конечный timeout,
проверка unknown-ответов и безопасные сообщения об ошибках.

Область: domain/session.ts, server/accounts.ts, client/session.ts, client/http.ts.
Проверки: malformed/401/403/409/500/network, CSRF, смена аккаунта во время
получения тела, abort/timeout, внешние адреса; npm run check, diff --check.
Коммит: feat(client): T174a добавить защищённый транспорт API

Экраны переключаются после подготовки всех адаптеров. Для небольших коммитов
UI сначала получает единый модуль доступа к данным с прежним локальным поведением;
затем один коммит переключает его на API вместе с авторизацией и реальными E2E.
Тестовый локальный адаптер не входит в итоговую клиентскую сборку.
