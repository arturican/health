# T200 — Доверенный исходный IP за прокси

Зависимость: T199. Статус — только в TASKS.md.

Результат: По умолчанию forwarded игнорируется; явный режим доверяет только ближайшему loopback proxy. Nginx заменяет входной X-Forwarded-For адресом клиента. Чужой IP не исчерпывает общий бюджет.

Файлы/объём: app/config/runtime, deploy/nginx.conf, .env.example; тесты, DEPLOYMENT/PRIVACY_SECURITY.

Проверки: Целевые HTTP/config/runtime; npm run check; build:api; Python deploy; локальный nginx.

Один этап — один локальный коммит. Без push, деплоя, изменения реальных данных
и новых зависимостей; T205 требует отдельного разрешения по AGENTS.md.
