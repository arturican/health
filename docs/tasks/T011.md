# T011 — Первичное заполнение профиля через интерфейс

Зависимость: T010.

Наблюдаемый результат: Первичное заполнение профиля через интерфейс.

## Критерии

- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/ProfilePage.tsx`, `src/ui/actions.tsx`, `src/ui/Field.tsx`, `src/App.tsx`, `src/styles.css`, `src/pages/ProfilePage.test.tsx`, `src/pages/ProfilePage.browser.test.tsx`, `package.json`, `package-lock.json`.
