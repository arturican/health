# T169c — API версий плана

Зависимость: T169b. GET /energy-plans — страницы по убывающей revision;
GET /energy-plans/effective/:date — действующая версия либо null.
POST принимает id, value EnergyPlanInput и expectedRevision (null для первой).
Снимок профиля/последнего веса и возраст формирует сервер; старые версии неизменны.
UUID создания служит ключом команды: повтор возвращает прежний результат.

Область: planRecords.ts, planRoutes.ts, runtime.ts и HTTP-тесты.
Проверки: отсутствие, все методы, дата, снимок, версии/пагинация, повтор,
конкурентная запись и другой владелец; npm run check, diff --check.
