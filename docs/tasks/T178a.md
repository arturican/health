# T178a — Публикация и проверка HTTPS

Зависимость: T177. Доставить проверенный frontend через существующий installer,
без push/PR. Добавить отдельный live smoke: UI login, восемь экранов, графики,
синтетические вложения, CRUD веса с очисткой только собственной тестовой записи,
reload, cookie, 401/CSRF. Credentials читаются из закрытого файла вне Git;
trace/video/автоматические screenshots выключены для исключения пароля.
Тесты последовательны, фиксируют календарный день из демонстрации.

Проверки: полный npm run check, verify_build, deployed Desktop/mobile,
release SHA/HTTPS/редирект, отсутствие внешних запросов/ошибок/переполнения.
Завершённая публикация отдельно от восстановления БД (T178b).
