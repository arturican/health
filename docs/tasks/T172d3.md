# T172d3 — Проверка файлов полной копии

Зависимость: T172d2. prepareFullImport проверяет структуру/связи/квоты и даты
по дню аккаунта, декодирует base64, проверяет контейнер и реальные пиксели,
сопоставляет размеры фото с карточками. Подготовка завершается до транзакции БД.

Область: prepareFullImport.ts, синтетическая полная копия и тесты.
Проверки: исходные PDF/JPEG байты, неверные размеры/контейнер/связи/квоты,
сохранность входа; npm run check и diff --check.
Коммит: feat(api): T172d3 проверять файлы полной копии
