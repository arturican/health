# T221 — Актуальные инструкции агентов и запуска

Зависимость: T220. Статус — в TASKS.md.

P2. Корневые инструкции повторяют карту/стандарты и безусловно требуют остановки
после одного коммита даже при нескольких согласованных этапах. README отрицает
уже реализованную регистрацию/постоянные лимиты; TEST_CASES требует отказа
серверного дневника без IndexedDB вопреки коду и E2E.

Результат и критерии:
Краткий корень с общими правилами, ответственности клиент/API/данные и ссылки
на карту; особенности UI и сервера во вложенных AGENTS. Команды сверены с
package.json/CI и успешными проверками. Явное разрешение всей очереди учитывается;
новые идеи/неразрешённые операции не добавляются. README и критерии актуальны.

AGENTS.md, src/pages/AGENTS.md, src/server/AGENTS.md, WORKFLOW/PROJECT_MAP,
README/TEST_CASES и TASKS/PROGRESS. check-docs включает Markdown из src,
чтобы проверять ссылки новых вложенных AGENTS. Проверки: check:docs/diff,
ESLint скрипта и воспроизведение отказа при неверной ссылке вложенного файла.
Приложение не меняется; полный check выпуска выполняется перед push.
Не менять личные настройки агента, подключения, модели или глобальный Git.
Отдельный коммит, затем следующий согласованный этап.
