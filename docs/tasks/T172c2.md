# T172c2 — Текстовый экспорт владельца

Зависимость: T172c1. GET /api/v1/backup/text возвращает совместимую v1-копию
из одного REPEATABLE READ снимка. Только владелец, no-store, attachment;
никаких credentials/sessions/commands. Размер ≤20 MiB, одна операция копии
одновременно на процесс, включая передачу ответа.

Область: textSnapshot.ts, backupTransport.ts, backupRoutes.ts, runtime.ts.
Проверки: все текстовые области/снимки/null/0, пустой аккаунт, изоляция,
неавторизованный доступ, лимит размера и параллельности; npm run check, diff --check.
