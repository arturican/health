# T188 — Модель email и токенов аккаунта

Зависимость: T187. Результат: аддитивная миграция позволяет хранить email,
момент подтверждения и хеши токенов двух назначений; старые аккаунты сохраняются.

Область: migrations/012_account_email.sql, PostgreSQL integration-тесты,
краткая спецификация модели, TASKS.md и PROGRESS.md. Новых зависимостей нет.

Политика адресов: непустые dot-atom ASCII адреса, локальная часть до 64 байт,
адрес до 254 байт, DNS-домен в нижнем регистре с минимум двумя метками,
каждая до 63 символов. Unicode/quoted local-part и IP literals пока не поддержаны;
ASCII punycode допустим. Локальная часть сохраняет регистр для доставки,
уникальность аккаунта проверяется по lower(email). Точки и +tag не удаляются.
Преобразование пользовательского ввода появится в отдельном API-этапе;
БД принимает только подготовленный формат. Старые аккаунты имеют NULL email,
им нельзя придумывать адреса или автоматически назначать подтверждение.

Токен: hash SHA-256 в lower hex, владелец FK, назначение verify_email либо
reset_password, снимок email, created_at/expires_at/consumed_at. Только конечные
моменты времени, expires > created; consumed находится в [created, expires).
Одна строка на владельца и назначение, удаление пользователя каскадно удаляет
токены. Исходный секрет не хранится. Runtime не получает CRUD токенов или
дополнительные права на users. Генерация, сроки конкретных операций, атомарное
одноразовое погашение и отзыв сессий реализуются следующими отдельными задачами.

Критерии: формат/границы/некорректный ввод/NULL, уникальность с учётом регистра,
сохранение +tag и точек, FK/назначение/хеш/время, каскад, ограничения runtime,
применение новой миграции поверх существующего аккаунта и сессии без потерь.
Проверки: целевые PostgreSQL, полный npm run check, build:api, git diff --check.
В интерфейсе изменений нет; миграция не применяется к рабочей БД этим шагом.

Основания: [OWASP email](https://cheatsheetseries.owasp.org/cheatsheets/Email_Validation_and_Verification_Cheat_Sheet.html),
[OWASP recovery](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html).
