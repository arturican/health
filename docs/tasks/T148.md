# T148 — Компоновка питания

Зависимость: T147. Отдельные карточки итогов и баланса, журнал рядом с вводом,
каталог рядом с редактором продукта. На узком экране одна колонка; поля,
поиск, архив, копирование, подтверждения и возврат фокуса сохраняются.
Файлы: NutritionPage, FoodJournal, ProductCatalog, nutrition.css, macro-charts.css.
До 250 строк реализации, без изменения хранения и формул.

Проверки: npm run check, просмотр страницы с синтетической порцией,
git diff --check. Коммит: `feat(nutrition): T148 перенести компоновку макета`.
