# T052 — ручные лабораторные показатели с документом-источником

Зависимость: T051.

Наблюдаемый результат: ручные лабораторные показатели с документом-источником.

## Критерии

- Показатель имеет UUID, documentId, дату не в будущем, название, числовой результат с оператором (=/< /≤/>/≥) либо непустой текст, единицы, референс как на бланке и заметку.
- Числа конечные, включая ноль/отрицательные; текст/единицы/референсы не угадываются и не интерпретируются. Неизвестные поля/невалидные значения отвергаются.
- DB12 добавляет labResults с индексом documentId; сохранение атомарно проверяет существующий документ и не допускает осиротевшие показатели при конкурентном удалении.
- Обычное удаление документа с показателями блокируется до отдельного подтверждения каскада в T054; отсутствие показателей сохраняет поведение T051.
- Список повторно валидируется и упорядочен по датам/ID; чистый форматтер сохраняет знак и точность, без оценки нормы/диагноза.
- Unit и Chromium проверяют значения/связи, reopen/миграцию/rollback, отсутствие изменения исходного файла и no external HTTP.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/labResult.ts`, `src/data/labRepository.ts`, `src/data/db.ts`, `src/data/documentRepository.ts`.
