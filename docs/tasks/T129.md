# T129 — концепт главной страницы в Figma

Зависимость: T128. Пользователь предоставил Figma-файл health и уточнил:
сначала переработать макет в Figma. Это отдельный концепт по новому референсу;
прежняя очередь T077–T119 не запускается автоматически.

## Результат

Один редактируемый Desktop-экран «Сегодня», ширина 1440 px, в тёмной палитре
предоставленного набора карточек. Навигация текущего MVP, сводка дня, динамика
веса, питание и активность. Только явно отмеченные синтетические демоданные.
Исходные страницы референса сохраняются; код приложения не меняется.

## Критерии и проверки

- Использованы подходящие существующие компоненты; связанные элементы имеют
  Auto Layout, тексты и графика редактируются отдельно.
- Есть единицы и даты; отсутствие записи не показано нулём. Калорийная цель
  отделена от оценки расхода; цвет не оценивает здоровье.
- Проверены структура узлов, шрифт Roboto, отсутствие изображений всего UI,
  переполнения и наложений; просмотрен итоговый скриншот и проверен контраст.
- Ссылка на итоговый frame и ограничения концепта записаны в PROGRESS.md.
- `npm run check:docs`, `git diff --check`; отдельный локальный коммит.

Пользователь следующим запросом разрешил продолжить Desktop и сделать мобильную
версию. Мобильная адаптация выполняется последовательно отдельной задачей
[T130](T130.md). Полный набор состояний и перенос в приложение остаются
отдельными последующими этапами.

Коммит: `docs(design): T129 создать концепт главной в Figma`.
