# T076 — подготовить Figma и очередь дизайн-задач

Зависимость: T075.

## Разрешённый результат

Только подготовка: изучить существующий проект, фактически проверить доступность
Figma, предложить подключение и записать небольшие следующие задачи. Пользователь
уточнил, что Design-файл и макеты нужно создать с нуля. После отчёта остановиться.

## Критерии

- Проверены стек, текущий дизайн, документы, существующие UI и design-тесты.
- Среда, каталог плагинов и инструменты сеанса проверены; подключение и права
  не объявляются успешными без реальной проверки.
- Предложен способ подключения для desktop app; CLI-команды проверены через help,
  существующая конфигурация просмотрена без вывода секретов и без дублирования.
- OAuth выполняет пользователь; отсутствие инструментов создания нативных
  элементов явно отделено от заявленных в каталоге возможностей.
- План начинается с нового файла и главной 1440/390, делит токены, компоненты,
  группы иконок, каждый график и экран; следующие задачи не выполняются.
- Используются существующие DESIGN.md, TASKS.md, IDEAS.md, PROGRESS.md.
- Только документация; check:docs и diff-check проходят, один отдельный коммит.

Figma-файл, редактируемость и права проверяются после установки/OAuth в T077;
пока нет авторизации, честный результат подготовки — описание ограничения.
Runtime, зависимости, глобальная MCP-конфигурация и макеты не меняются.

Коммит: `docs(design): T076 подготовить подключение Figma и план дизайна`.
