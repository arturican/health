# T227 — Боковое меню не перекрывает аккаунт

Зависимость: T222. Статус — в TASKS.md.

При прокрутке desktop-страницы закреплённая навигация накладывается на
карточку хранения, резервной копии и выхода. Ограничить sticky-меню его
областью сетки перед карточкой; сохранить внутреннюю прокрутку короткого
меню и мобильное расположение.

Критерии:
- На desktop при прокрутке до карточки меню и карточка не пересекаются.
- Резервная копия, выход и все разделы доступны мышью и клавиатурой.
- При ширине 1023 px и меньше сохраняется порядок меню → страница → карточка,
  без горизонтального переполнения.

Файлы: src/App.tsx, src/shell.css, tests/e2e/responsive.spec.ts,
карточка, TASKS/PROGRESS. До двух файлов приложения, до 250 строк реализации.
Проверки: сначала падающая E2E-регрессия, затем связанные responsive E2E,
визуальная проверка синтетических desktop/mobile-снимков, полный npm run check,
git diff --check и review staged diff. Один локальный коммит; без push/деплоя.
