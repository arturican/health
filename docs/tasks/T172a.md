# T172a — Настройки и версия дневника

Зависимость: T171d. Одна строка настроек на аккаунт: видимость разделов,
отметка каталога, revision и generation для будущей защиты от запоздавших записей.
Отдельные legacy_metadata сохранят неизвестные поля старых полных копий без потерь.
GET /diary-state создаёт начальные настройки; PUT /settings требует revision.

Область: миграция 008, diaryState.ts, settingsRoutes.ts, runtime.ts, тесты.
Проверки: свежие миграции, ограничения/FK/RLS, чтение/правка/конфликт, неизвестные
поля и чужой доступ; npm run check, diff --check.
