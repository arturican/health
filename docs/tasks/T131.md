# T131 — объединить dev и устранить конфликт ID задач

Зависимости: T128 и T130. Пользователь попросил выполнить pull и переписать
конфликтующие документы. До pull рабочее дерево было чистым.

## Результат

- Объединить origin/dev с локальными коммитами, сохранить обе реализации.
- Удалённые T127/T128 остаются исправлениями фокуса. Локальные архитектура
  и API становятся T129/T130; следующий запуск API получает T132.
- Исправить карточки, TASKS, PROGRESS, SERVER_STORAGE и DEPENDENCIES.
- Сохранить историю Git и зафиксировать карту старых/новых ID.
- Не изменять серверы, медицинские данные и настройки публикации.

Проверки: целевые тесты фокуса/копии/веса/API, полный `npm run check`,
Python-тесты установщика, Markdown-ссылки, отсутствие конфликтных маркеров
и дублирующихся ID, `git diff --check`. Runtime-файлы из origin/dev должны
совпадать с удалённой версией, src/server — с локальной до merge.

Коммит объединения:
`chore(sync): T131 объединить dev и устранить конфликт ID задач`.
