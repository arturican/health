# T155 — Подготовка графиков анализов

Зависимость: T154. Чтение показателей с документами-источниками одной
транзакцией; группы по точным названию и единицам без пересчёта единиц.
График показывает точные числа. Текст, операторы сравнения и записи без
единиц остаются в истории. Не соединять через такие записи и повторные даты.
Никакой медицинской интерпретации референсов или направления изменения.

Для отображения брать последние 100 записей выбранного ряда, сохраняя полное
число записей и сами данные. Координаты конечны даже для крайних чисел.
Файлы: domain/labPlot.ts и data/labHistoryRepository.ts, до 250 строк.
Проверки: обычные, граничные, неверные и пустые данные, связи с источником,
npm run check, git diff --check. UI подключается в T156.

Коммит: `feat(labs): T155 подготовить ряды показателей для графика`.
