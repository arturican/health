# T014 — Журнал веса с редактированием и подтверждением удаления

Зависимость: T013.

Наблюдаемый результат: Журнал веса с редактированием и подтверждением удаления.

## Критерии

- Нет профиля — доступна ссылка создания; нет измерений — честное пустое состояние.
- Добавление/повторная дата/редактирование/отмена переживают повторное открытие.
- Удаление требует отдельного подтверждения; отмена не удаляет запись.
- Ошибка поля связана с вводом и фокусирует первое неверное поле.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/pages/WeightPage.tsx`, `src/ui/Confirmation.tsx`, `src/App.tsx`, `src/styles.css`, `src/pages/WeightPage.test.tsx`, `src/pages/WeightPage.browser.test.tsx`.
