# T172b1 — Повторяемые команды и generation

Зависимость: T172a. withCommand проверяет X-Diary-Generation под блокировкой
владельца в транзакции записи. Idempotency-Key сохраняет результат команды
атомарно; повтор возвращает результат, изменённое тело с тем же ключом — 409.
Первый подключённый маршрут — PUT /settings. Остальные подключаются T172b2–b4.

Область: writeCommand.ts, commands.ts, settingsRoutes.ts и тестовый помощник.
Проверки: повтор/параллельный повтор, неверный ключ/поколение, конфликт тела,
два владельца и rollback; npm run check, diff --check.
Коммит: feat(api): T172b1 защитить повторные команды
