# T030 — Атомарное восстановление текстовой копии с согласием

Зависимость: T029.

Наблюдаемый результат: Атомарное восстановление текстовой копии с согласием.

## Критерии

- Полная повторная проверка входа предшествует единой транзакции замены пяти текстовых таблиц.
- Ошибка любой записи откатывает всю замену; другие служебные данные сохраняются, сбрасывается только флаг примеров каталога.
- Кнопка восстановления доступна после предпросмотра и явного согласия; отмена не меняет базу.
- Production E2E скачивает файл, изменяет профиль, импортирует копию и проверяет результат после перезагрузки.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/backupRepository.ts`, `src/pages/SettingsPage.tsx`, `src/ui/actions.tsx`; связанные тесты и `tests/e2e/text-backup.spec.ts`.
