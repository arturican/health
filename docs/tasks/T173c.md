# T173c — Начальный каталог через API

Зависимость: T173b. POST /products/seed сохраняет существующее поведение:
два учебных продукта только при отсутствии маркера, без перезаписи совпавших UUID.
Квоты и транзакция владельца обязательны; полные метаданные не переполняются.
Демонстрационный дневник с маркером не получает дополнительные примеры.

server/seedProducts.ts, server/productRoutes.ts.
