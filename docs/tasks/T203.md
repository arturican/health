# T203 — Очистка восстановленных секретов доступа

Зависимость: T202. Статус — только в TASKS.md.

Результат: Административный SQL для изолированной restore-БД атомарно удаляет сессии и одноразовые ссылки, сохраняя дневники. Ошибочное имя БД и runtime-роль не могут выполнить очистку.

Файлы/объём: deploy/revoke-restored-access.sql, SQL-регрессии, tests/serverDatabase.ts, BACKUPS/PRIVACY_SECURITY.

Проверки: Настоящая локальная PostgreSQL: отзыв, повтор, отказ и сохранность данных; npm run check; Python deploy.

Один этап — один локальный коммит. Без push, деплоя, изменения реальных данных
и новых зависимостей; T205 требует отдельного разрешения по AGENTS.md.
