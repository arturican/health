# T061c — аудит всех экранов и браузерного интерфейса тестов

Зависимость: T061b.

Наблюдаемый результат: аудит всех экранов и браузерного интерфейса тестов.

## Критерии

- Production Playwright проходит все 8 разделов на Desktop Chrome и Pixel 7: h1, skip link/фокус main, доступное имя следующего элемента и отсутствие горизонтального переполнения.
- axe-core проверяет все экраны; заполненные формы/диалоги дополнительно покрыты браузерными сценариями предыдущих этапов. Результат не выдаётся за проверку screen reader, Firefox или Safari.
- Vitest Browser UI реально открывается в Chromium: список файлов/тестов, выбор и просмотр результата кликами. Сервер тестов не входит в production.
- Контрольные снимки desktop/mobile содержат только синтетические данные, перед fullPage-снимком прокрутка возвращена к началу страницы.
- Нет ошибок страницы/консоли и внешних HTTP. Фактические результаты и ограничения записаны в PROGRESS.

## Фактическая проверка

- Production accessibility: 2/2 сценария, 8 экранов × 2 проекта = 16 axe-аудитов без нарушений; клавиатура/skip link/имена/переполнение — OK.
- Отдельный заполненный дневник создан настоящими формами на 375 и 1280 px: питание 300, общий расход 2100, баланс 1800 ккал. Ошибок и внешних HTTP нет; снимки desktop/mobile просмотрены.
- Vitest UI запущен с полным набором: 30 файлов/67 тестов PASS. В целевом просмотре файл RecordFocus раскрыт/свёрнут, тест выбран кликом, открыты Report и Console; URL содержит file/test и Report сообщает успешный результат. Console содержит ожидаемый синтетический QuotaExceededError из fault injection.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `tests/e2e/accessibility.spec.ts`.
