# T055b — полный экспорт из настроек

Зависимость: T055a. Часть разрешённого полного локального MVP.

## Критерии

- Все таблицы читаются одним согласованным снимком; файлы проверяются по содержимому, кодируются вне транзакции без изменения оригинала.
- Настройки явно различают текстовую и полную копии; полная содержит фото/документы/показатели и служебные настройки. Кнопка скачивает локальный JSON, ошибки сохраняют данные, повторный запуск блокируется.
- Текстовое восстановление сохраняет файлы/документы/показатели; полная копия не зашифрована, лимиты и содержание объяснены.
- Unit/Chromium подтверждают полный состав, байты, согласованность, локальное скачивание/освобождение ссылок и no external HTTP.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/media/checkBackupFile.ts`, `src/data/fullBackupRepository.ts`, `src/pages/FullBackupExport.tsx`, `src/pages/SettingsPage.tsx`.

Файлы повторно проверяются по сигнатуре/MIME/размеру и настоящему декодеру;
размеры JPEG фото должны совпасть с карточкой, bitmap освобождается при любом результате.
