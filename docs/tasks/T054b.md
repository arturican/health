# T054b — подтверждённое удаление документа с показателями

Зависимость: T054a. Часть разрешённого полного локального MVP.

## Критерии

- Подтверждение показывает количество показателей документа; обычное удаление с показателями остаётся заблокированным.
- Явное подтверждение удаляет документ, файл и связанные показатели одной транзакцией; отмена сохраняет всё, поздний отказ откатывает все таблицы.
- Количество проверяется ещё раз внутри RW; изменение данных после показанного подтверждения требует повторного согласия.
- UI сохраняет соседние документы/показатели, корректно обрабатывает исчезнувший источник и фокус после отказа/удаления.
- Unit/Chromium проверяют каскад, отмену, гонку/rollback, байты, remount и 375 px/axe/no HTTP.
- npm run check, diff check и отдельный коммит.

Файлы этапа: `src/data/documentRepository.ts`, `src/pages/DocumentList.tsx`.
