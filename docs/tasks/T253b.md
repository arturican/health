# T253b — Состояние и доставка watchdog

После T253. Подготовить deploy/watchdog_monitor.py и service/timer без активации.
Два последовательных одинаковых наблюдения подтверждают отказ/восстановление.
Первое здоровое состояние не отправляет письмо. Одинаковые отказы
дедуплицируются; ошибка SMTP не записывается как доставка. После рестарта
состояние сохраняется; конкурентные запуски сериализуются.

Приватные config/state 0600 и каталог 0700; фиксированный localhost SMTP,
никаких адресов/ответов API в stdout. Использовать существующие проверенные
private_json, validate_config и atomic write_state из backup_monitor.
Конфигурация имеет тот же формат, directory/max_age_hours зарезервированы
для offsite-проверки, здесь не используются. Unit ограничивает сеть localhost,
файловую систему и время; timer каждые пять минут.

До 3 файлов реализации, 250 строк; unittest состояния, SMTP, приватности,
конкуренции, native systemd-analyze verify (с временными путями), check:docs/diff.
Без установки, конфигурации SMTP, настоящих писем и заявлений о закрытии AUD-011.
