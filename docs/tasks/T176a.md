# T176a — Приём зашифрованных копий

Зависимость: T175g. Один Python-приёмник для forced SSH command.
Только ожидаемое имя и SHA256; поток ограничен размером и свободным местом.
Запись 0600 во временный файл, fsync, публикация без перезаписи; безопасный
повтор идентичного файла. Сохраняются 14 последних копий приложения, исходные
снимки кластера и посторонние файлы не удаляются. Без распаковки/расшифровки.

Проверки: реальные временные файлы, плохое имя/хеш/лимиты, symlink, повтор,
конфликт, retention и очистка частичного файла; тесты deploy, npm run check,
diff --check. Установка и действующий cluster backup — в T176b.
Коммит: feat(backup): T176a принимать зашифрованные копии без перезаписи
