# T172d2 — Текстовое восстановление

Зависимость: T172d1. POST /backup/text принимает UTF-8 JSON как
application/vnd.health-diary+json, ≤20 MiB. Авторизация/лимит параллельности
и обязательные ключ, generation, changeRevision проверяются до чтения тела.
X-Import-Mode: empty (default) либо replace после явного подтверждения UI.
Восстановление атомарно, сохраняет вложения/видимость, сбрасывает отметку каталога,
меняет generation и удаляет старые команды. Повтор импорта возвращает результат.

Область: importRows.ts, restoreText.ts, importRequest.ts, backupRoutes.ts, commands.ts.
Проверки: round-trip, repeat, stale/occupied, два владельца, rollback, неверное
тело/заголовки/размер, полный журнал команд; npm run check, diff --check.
Коммит: feat(api): T172d2 восстанавливать текстовый дневник
