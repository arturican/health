# T058c — подтверждённое атомарное удаление всего дневника

Зависимость: T058b.

Наблюдаемый результат: подтверждённое атомарное удаление всего дневника.

## Критерии

- Отдельная кнопка открывает alertdialog с полным описанием удаления; фокус сначала на отмене. До подтверждения база не меняется.
- Подтверждённое действие очищает все 13 таблиц приложения одной RW-транзакцией, включая файлы и настройки; другие базы браузера не затрагиваются.
- Pending блокирует повтор/отмену; поздняя ошибка откатывает все таблицы и оставляет подтверждение для повтора. Успех закрывает диалог и возвращает фокус.
- После успешной очистки сбрасываются открытые черновики, выбранные файлы и предпросмотры в настройках; при отказе они сохраняются.
- Интерфейс объясняет отсутствие отмены без резервной копии и то, что скачанные копии удаляются пользователем отдельно. После очистки приложение пригодно для нового дневника.
- Unit/Chromium проверяют все таблицы, reopen, соседнюю базу, отмену/подтверждение, ошибку/повтор, фокус и доступность.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/clearDiary.ts`, `src/pages/DeleteDiary.tsx`, `src/pages/SettingsPage.tsx`.
