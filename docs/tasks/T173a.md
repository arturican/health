# T173a — Согласованные демонстрационные данные

Зависимость: T172e. Детерминированная полная копия одного вымышленного человека:
90 дней веса, питания, шагов/тренировок, три плана, геометрические JPEG,
настоящие учебные PDF и ручные числовые/текстовые показатели.
Есть пропуски, неполные дни, неизвестные макронутриенты и архивный продукт.
Никаких медицинских рекомендаций, реальных людей или секретов.

Область: demoProducts.ts, demoText.ts, demoPdf.ts, demoBackup.ts (до 250 строк).
Проверки: повторяемость, даты/связи/история, валидаторы текста и полных файлов,
PDF offsets; npm run check, diff --check. Загрузка в БД — T173b.
