# T059 — сквозные сценарии дневника в production Chromium и Pixel 7

Зависимость: T058c.

Наблюдаемый результат: сквозные сценарии дневника в production Chromium и Pixel 7.

## Критерии

- Playwright использует собранное приложение без mock React/репозиториев и выполняет реальные ввод/клики/перезагрузку на Desktop Chrome и Pixel 7 375 px.
- Питание: создание своего продукта, запись/редактирование/копирование еды, сохранение снимков после изменения/архива, явная полнота и отсутствие данных.
- Активность/планы: шаги, тренировка, неизвестные и нулевые значения, изменение/удаление, версии планов и отсутствие двойного учёта расхода.
- Выбор дня согласован между Сегодня/Питание/Активность; историческая сводка, график и его доступное описание соответствуют введённым данным, перезагрузка сохраняет записи.
- Каждый сценарий проверяет отсутствие ошибок/внешних HTTP и горизонтального переполнения. Только синтетические данные, без произвольных задержек.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `tests/e2e/nutrition-day.spec.ts`, `tests/e2e/activity-plan.spec.ts`, `tests/e2e/day-navigation.spec.ts`.
