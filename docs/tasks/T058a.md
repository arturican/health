# T058a — строгие сохраняемые настройки видимости разделов

Зависимость: T057.

Наблюдаемый результат: строгие сохраняемые настройки видимости разделов.

## Критерии

- Версия настройки 1 содержит только два boolean-флага showPhotos/showDocuments. Неизвестные ключи/версии/строки вместо boolean отклоняются; ошибки не содержат исходного JSON.
- Отсутствующая настройка означает видимость обоих разделов. Чтение не записывает defaults, сохранение меняет только metadata данной настройки и сохраняется после reopen.
- Полная копия проверяет известную настройку до записи; старые копии без неё допустимы. Текстовое восстановление оставляет видимость, полное восстанавливает её.
- Unit и настоящий IndexedDB Chromium проверяют варианты, повреждение, отказ записи без потери данных и состав копий.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/visibility.ts`, `src/data/visibilityRepository.ts`, `src/domain/fullBackup.ts`.
