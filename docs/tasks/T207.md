# T207 — Повторяемое синтетическое восстановление

Зависимость: T206. Статус — в TASKS.md.

Результат: тест полного PostgreSQL dump → GPG → decrypt → pg_restore,
включённый в обычный npm run check. Только выделенная loopback health_test,
случайные source/restore БД из существующего testDatabase и временный GPG key.
Клиенты PostgreSQL — уже используемый образ postgres:18.3, Docker --pull=never,
без загрузки образа или обращения к production. Пароль только в env процесса.

Критерии: снимок всех таблиц/байтов совпадает, checksum миграций проверяется,
RLS/ACL сохраняются, чужой пользователь не видит записи, SQL T203 отзывает
сессии/ссылки без изменения остальных данных. Повреждённый ciphertext/dump
не принимается; pg_restore применяет --single-transaction/--exit-on-error.
Все созданные БД/роли/ключи очищаются; реальные ключи/архивы не читаются.

Файлы: новый server/backupRestore.test.ts, TESTING/BACKUPS, TASKS/PROGRESS.
Проверки: целевой Vitest, npm run check, Python deploy, verify_build, diff check.
Один локальный коммит; push/деплоя/настоящих отправок нет.
