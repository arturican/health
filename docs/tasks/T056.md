# T056 — проверка полной копии и предпросмотр без записи

Зависимость: T055b.

Наблюдаемый результат: проверка полной копии и предпросмотр без записи.

## Критерии

- Файл проверяется на пустоту и 200 MiB до чтения; JSON читается строго в UTF-8, неверные формат/версия/связи/Base64 отклоняются.
- Все вложения проверяются до предпросмотра: реальные байты, MIME, размеры, декодируемость изображений и размеры фото; EXIF в подготовленном фото отклоняется. Документы сохраняют исходные байты.
- Полностью проверенный предпросмотр показывает все разделы, число файлов и байт; до T057 он не изменяет базу. Выбор нового файла или отмена очищает старый предпросмотр.
- Ошибка не раскрывает содержимое файла. Повторные действия блокируются, bitmap освобождается. Unit и настоящий Chromium проверяют корректную копию и отказы без записи в базу.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/photoExif.ts`, `src/media/checkBackupFile.ts`, `src/media/fullBackupFile.ts`, `src/pages/FullBackupImport.tsx`, `src/pages/SettingsPage.tsx`.
