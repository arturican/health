# T175c2 — Операции вложений и показателей

Зависимость: T175c1. Пять клиентских модулей: upload, фото, документы,
показатели, история показателей. Контекст захватывается до обработки файла.
Повтор определяется содержимым файла и метаданными, сохраняет исходные UUID.
Правка передаёт исходную revision; количество показателей сверяется с версией
документа из открытого подтверждения. История читается согласованно.

Проверки: клиент/Fastify/PostgreSQL — байты, CRUD, повтор загрузки, связанные
показатели и каскад, конфликт подтверждения, чужой аккаунт, поздняя подготовка.
Фото синтетическое; browser-декодер отдельно покрыт существующими тестами.
npm run check, diff --check.
