# T010 — Атомарное создание профиля и первого измерения

Зависимость: T009.

Наблюдаемый результат: Атомарное создание профиля и первого измерения.

## Критерии

- Профиль и первое измерение валидируются до записи; ID измерения UUID.
- Создание выполняется одной rw-транзакцией; ошибка второго добавления не оставляет профиль.
- Уже существующий профиль не перезаписывается; дата измерения не в будущем и не раньше известной даты рождения.
- getProfile возвращает null для пустой базы и runtime-валидирует данные при чтении.

- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/profileRepository.ts`, `src/data/profileRepository.test.ts`.
