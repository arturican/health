# T043 — проверка содержимого и размера вложений

Зависимость: T042a.

Наблюдаемый результат: проверка содержимого и размера вложений.

## Критерии

- Фото: JPEG/PNG/WebP ≤10 MiB; документы: эти форматы и PDF ≤20 MiB. Пустые файлы и иной ввод отклоняются до чтения.
- Тип определяется по сигнатуре; объявленный непустой MIME должен совпадать. Пустой MIME распознаётся по содержимому, имя/расширение не используются.
- JPEG/PNG имеют завершающий маркер; WebP имеет согласованные RIFF-размер и первый ненулевой image-chunk; PDF имеет заголовок 1.0–1.7/2.0 с CR/LF и EOF в последних 1024 байтах.
- Это структурная проверка формата; декодирование фото добавляется T045. SVG/HTML/исполняемые файлы и подмена MIME отклоняются.
- Возвращается Blob с каноническим MIME; ошибки чтения дают общее сообщение без содержимого файла. Границы и реальные Blob проверены unit/browser.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/domain/attachment.ts`.
