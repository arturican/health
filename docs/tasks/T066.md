# T066 — стиль Telegram / Material и пиктограммы

Зависимость: T065.

- Светлые поверхности, синие акценты, согласованные hover/focus/selected состояния и типографика.
- Официальные Material Symbols Rounded поставляются локальными SVG-путями, источник и Apache-2.0 сохранены; нет внешних шрифтов и новых npm-зависимостей.
- Иконки декоративны и не меняют доступные имена, маршруты, фокус и видимость разделов.
- Адаптация 320–1440 px, низкое меню и полный npm run check проходят; отдельный коммит.
