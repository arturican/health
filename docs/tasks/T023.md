# T023 — Запись еды с независимым снимком продукта

Зависимость: T022.

Наблюдаемый результат: Запись еды с независимым снимком продукта.

## Критерии

- Запись фиксирует снимок названия/значений/источника, массу, дату и приём пищи.
- Правка и архивирование каталога не меняют старые записи; новые из архива запрещены.
- Миграция не теряет каталог, ошибка записи не создаёт частичные данные.
- Фактические записи не датируются будущим; данные проверяются при чтении.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/data/db.ts`, `src/data/foodRepository.ts`, `src/data/foodRepository.test.ts`.
