# T252a — Независимый канал оповещений

IMP-021 / AUD-011. Статус blocked: на frontend нет SMTP, provider monitoring
не подтверждён, ожидается ответ на вопрос о независимом пути.
Нужен выбранный транспорт и необходимый доступ: frontendSMTP с DNS/PTR,
либо существующий внешний SMTP/monitor. Пароли не присылать в чат/репозиторий.
Результат: конкретный проверяемый канал и безопасное расположение конфигурации,
privacy/failure/rollback условия и карточка установки при необходимости.
Зависимость T253a activation, не блокирует подготовкуprobe T253 иintegrity T254.
