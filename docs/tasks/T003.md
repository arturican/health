# T003 — контроль покрытия тестами

Зависимость: T002. Результат: воспроизводимый отчёт показывает, какая реализация
не проверена тестами; новые файлы не исчезают из отчёта автоматически.

## Критерии

- Совместимый coverage-provider Vitest закреплён точной версией.
- Отчёт включает весь код приложения, с обоснованным исключением точки запуска.
- Порог выбран по текущему поведению и записан в TESTING; недостаток покрытия
  не исправляется ослаблением порога или исключением бизнес-логики.
- Отчёт игнорируется Git; команда проверки покрытия включена в check.
- Проверен отрицательный случай: непокрытая ветка обнаруживается отчётом.

Не писать фиктивные функции ради процентов. Коммит:
`test(quality): T003 add coverage checks`.
