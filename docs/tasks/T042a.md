# T042a — десятичные значения в редакторах без потери точности

Зависимость: T042.

Наблюдаемый результат: десятичные значения в редакторах без потери точности.

## Критерии

- Числовые value/defaultValue поля показываются десятичной записью без группировки и экспоненты, сохраняя double-значение при разборе.
- Строки, пустое значение, checkbox/date/file/select и связь ошибок с label не изменяют поведение.
- Регрессия реального редактора веса: значение 0,0000001 открывается и сохраняется без изменения ID/даты/веса; ноль остаётся нулём.
- Реальный Browser проверяет повторное сохранение и отсутствие ошибок; базовые и предельные значения проверены unit-тестами.
- Поведение доступно через публичный API или интерфейс текущего этапа.
- Обычные случаи, ошибки и релевантные границы проверены тестами.
- Данные синтетические; отсутствие значения не заменяется нулём.
- npm run check и git diff --check проходят; изменения отдельным коммитом.

Файлы этапа: `src/ui/Field.tsx`.
