# T126 — автоматическая публикация dev

Зависимость: T125. Пользователь явно выбрал первый деплой и автоматические
обновления из dev через GitHub Actions.

## Результат

Успешный CI для push в dev публикует проверенный dist на dev.arturican.com.
PR и другие ветки не получают доступ к окружению деплоя.

## Объём

- Существующий check проверяет приложение и Python-установщик, сохраняет dist.
- Отдельный deploy job получает тот же артефакт после успешного check.
- GitHub environment health-dev допускает только dev. Отдельный SSH-ключ
  запускает только ограниченный установщик от health-deploy, без sudo и shell.
- SSH проверяет закреплённый ключ хоста; после доставки HTTPS возвращает SHA.
- Описаны повторный запуск, откат и обновление серверной конфигурации.

## Проверки

- `npm run check`, Python unittest, проверка workflow и `git diff --check`.
- Ограниченный ключ доставляет сборку и отклоняет посторонние команды.
- HTTPS показывает нужную версию, прежний релиз доступен для отката.
- После разрешённого push GitHub check/deploy проходят, сайт возвращает SHA
  опубликованного коммита. До разрешения push задача не считается завершённой.
- Секреты отсутствуют в Git и выводе инструментов.

Коммит: `chore(ci): T126 публиковать dev на VPS после проверок`
