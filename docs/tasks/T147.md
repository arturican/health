# T147 — Графики БЖУ из записанных порций

Зависимость: T146. Пиктограммы и граммы белков, жиров и углеводов за выбранный
день, диаграммы по приёмам пищи. Использовать действующий foodTotals, не вводить
медицинских норм и процентов достижения. Неизвестные макросы не заменять нулём.
Пустой неполный день и подтверждённый полный день различаются.

Файлы: NutritionPage, новый MacroCharts и macro-charts.css (до 250 строк).
Проверки: порции, неизвестные значения, пустота и смена дня; npm run check;
визуальная проверка в браузере; git diff --check.

Коммит: `feat(nutrition): T147 добавить графики БЖУ из порций`.
