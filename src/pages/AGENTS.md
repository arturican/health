# Экраны и формы

Общие правила — [корневой AGENTS](../../AGENTS.md).

- Данные только через ../dataAccess: client → авторизованный API. Не подключай
  Dexie к рабочим экранам; legacy alias допустим в изолированных unit/browser.
- Дату бери из DayContext; ответы выбранного дня/файла не смешивай со старыми.
  Загрузка, пустота, ошибка и повтор должны быть различимы.
- Формы используют Field/Feedback/useAction. При отказе сохраняй черновик.
  Если смена строки размонтирует форму, согласуй pending формы и журнала;
  во время удаления блокируй конфликтующий ввод. Возвращай осмысленный фокус.
- Для действий с ревизией используй useDiaryQueryState.current: старые данные
  остаются видимы при обновлении/ошибке, но действия ждут свежего чтения.
  Сохраняй исходный snapshot редактора; не повышай его ревизию автоматически.
  Cancel доступен при устаревании; фокус возвращай после включения поля.
- React state содержит пользовательский выбор/черновик, расчёты — в domain.
  Видимость разделов не заменяет авторизацию. Object URL освобождай.
- Проверяй роли/подписи/реальные действия, клавиатуру и узкий экран.
  Изменения сценария — regression + связанные Browser/E2E на синтетических данных.
  Шаблоны: PendingEditors/WorkoutPending, tests/e2e.
