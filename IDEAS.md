# Идеи продукта — не очередь разрешённых работ

В этом файле собраны будущие возможности. Наличие идеи не даёт Codex разрешения писать код. Для запуска: выбрать идею → описать проблему и проверку пользы → разбить на небольшие задачи → согласовать → добавить карточки и зависимости в TASKS.md.

## Не реализовывать как обещания продукта

Диагноз/степень ожирения/процент жира по фотографии; «чем больше дефицит, тем лучше»; обещание точного расхода калорий; гарантированное похудение по сумме ккал; публичный рейтинг веса; «проверенный врач» без проверки; «полная защита» только потому, что данные лежат в браузере.

## Проверка идеи

Для выбранной идеи заполнить: чья проблема; конкретный сценарий; что пользователь делает сейчас; минимальная проверка без разработки; признак пользы; риски; данные/разрешения; решение принять/отложить/отклонить. Одной формулировки «это круто» недостаточно для включения в очередь.
