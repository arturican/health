# Desktop-макеты дневника

Локальные концепты 1440 px по одобренному экрану «Сегодня» и предоставленному
SVG-референсу. Это статичные макеты, а не работающие формы приложения.
Откройте [галерею](index.html): рядом с каждым разделом доступны SVG и PNG,
а также отдельный лист редакторов и состояний.

## Состав готового пакета

8 основных экранов (включая одобренную главную) и 7 листов состояний:

| Задача | Раздел | Формы и состояния |
|---|---|---|
| Основа | [Сегодня](today-desktop.png) | Ранее одобренный экран |
| T136 | [Питание](nutrition-desktop.png) | [Порции, каталог, архив, копирование](nutrition-states.png) |
| T137 | [Активность](activity-desktop.png) | [Шаги, тренировки, удаление](activity-states.png) |
| T138 | [Вес](weight-desktop.png) | [Измерения, график, ИМТ](weight-states.png) |
| T139 | [Фото](photos-desktop.png) | [Сравнение, файлы, подписи](photos-states.png) |
| T140 | [Документы](documents-desktop.png) | [Бланки, показатели, удаления](documents-states.png) |
| T141 | [Профиль](profile-desktop.png) | [Первый запуск, правка, валидация](profile-states.png) |
| T142 | [Настройки](settings-desktop.png) | [Планы, копии, подтверждения](settings-states.png) |

Все новые разделы имеют ошибки, ожидание/сохранение и соответствующие пустые
состояния. Высота экранов зависит от содержания; ширина всех макетов 1440 px.
Числа иллюстрируют ввод, а не медицинские рекомендации. Дата демо — 15.10.2026;
экран активности показывает записи за 14.10.2026, чтобы не менять главную.

## Использование

Перетащите SVG на существующую страницу Design в Figma Starter.
Импорт не создаёт Auto Layout, Variables и связанные компоненты автоматически;
сохранение текста после импорта в Figma здесь не проверено.
Шрифт — приложенный Roboto; [лицензия шрифта](Roboto-LICENSE.txt).
Иконки взяты из приложения; [лицензия иконок](material-symbols-LICENSE.txt).
Все данные синтетические; в фото используются только геометрические заглушки.

Для воспроизведения из корня репозитория: `node design/desktop/render.cjs nutrition`
(замените имя на нужный модуль). Используется уже установленный Playwright;
новых зависимостей нет. Генератор создаёт SVG, PNG, отчёт проверок и галерею.
В минимальном WSL Chromium требует доступных системных библиотек;
настройки окружения не являются частью макетов.

Утверждённая главная сохранена как визуальная основа. T133 остаётся blocked
для нативной Figma-композиции; локальная очередь T136–T142 разрешена отдельно.
Адаптивность, Mobile и реализация frontend не входят в эту очередь.
